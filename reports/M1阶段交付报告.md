# PR01-02 第一阶段交付报告

日期：2026-09-11  
项目：启动子调控模式发现  
当前分支：`main`

## 1. 本阶段目标

完成从标准化 promoter metadata 到可复现实验输入的基础闭环，为后续 MEME/FIMO motif 发现提供统一输入和质量证据。

## 2. 已实现内容

### 数据层

- 定义 `sequence_id`、`species`、`source_dataset`、`sequence` 等最小字段；
- 支持 CSV/TSV 输入；
- DNA 序列统一为大写，`U` 显式转为 `T`；
- 过滤空序列、非法字符、必填字段缺失和过高 `N` 比例记录；
- 对重复 ID 和完全重复序列做精确去重；
- 按数据源划分 discovery/validation split；
- 生成保持单条序列长度和碱基组成的随机背景。

### M2 基础 EDA

- 按物种、数据源、σ 因子和 split 统计样本数；
- 汇总序列长度和 GC fraction；
- 汇总逐位置碱基组成；
- 生成长度/GC 分布图和 σ 因子数量图；
- 输出 `m1_manifest.json` 记录配置和产物。

### B0 可解释基线

- 使用 `TTGACA` 和 `TATAAT` 共识构造 PWM；
- 支持正负链扫描；
- 负链命中坐标转换回原序列坐标；
- 输出已知元件命中表和汇总表。

## 3. 验证结果

使用仓库内的最小 demo 输入进行代码验证：

- 输入记录：8 条；
- 质量过滤和去重后：6 条；
- 预处理测试：5 个全部通过；
- M1/M2 统一入口：成功生成 8 项产物；
- B0 PWM 扫描：成功输出命中表和汇总表。

上述数字只证明代码链路可运行，不代表真实物种分布、motif 统计显著性或生物学结论。

## 4. 运行入口

~~~bash
python -m pytest -q
python -m experiments.run_m1 --config configs/m1_demo.yaml
python -m experiments.known_element_scan \
  --input tmp/m1_demo_configured/promoters_clean.tsv \
  --output-dir tmp/m1_demo_configured/known_elements
~~~

真实数据运行时，将配置中的 `input` 替换为完成来源审计的 metadata 表，并将输出目录指向 `data/processed/` 或 `results/`。不应把 demo 产物作为正式实验结果提交。
