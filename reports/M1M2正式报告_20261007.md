## 1. 项目背景与任务定义

### 1.1 项目背景与动机

转录起始是基因表达调控的第一道关口。细菌 RNA 聚合酶本身不能识别启动子，需要由 σ 因子引导并结合到启动子的核心元件上——主要是位于转录起始位点（TSS）上游约 35 bp 的 -35 box 与约 10 bp 的 -10 box。在核心元件之外，UP element、激活子结合位点、抑制子结合位点等辅助元件进一步影响调控的特异性与强度。

这些元件的共同特点是：序列短（通常 6–10 bp）、存在简并和变异、在核心元件之外的位置与排列方式并不固定。因此，要回答"启动子是如何被识别的、不同类型的启动子有何差异"，不能只看少数几个模式序列，而需要系统地在多物种启动子序列中刻画这些模式的组成、位置与间距，并检验其统计可靠性。

### 1.2 核心挑战

| 编号 | 挑战 | 本项目中的具体表现 | 应对方式 |
| --- | --- | --- | --- |
| C1 | 信号弱、motif 简并 | 教科书共识串在真实启动子中出现率仅 3.27%（-35）与 5.76%（-10） | 同时报告精确匹配与 ≤1 错配敏感性两种口径；辅以逐位置碱基偏好分析 |
| C2 | 背景碱基组成不均一 | 物种间 GC 中位数从 24.691% 到 60.494%；TJU 正样本 GC 系统性低于同物种天然对照 | 统一使用 `dinucleotide_null`（保持二核苷酸组成的打乱序列）作背景，逐文件配对 |
| C3 | 注释口径不统一 | 三个来源的 σ 命名体系不同（`Sigma70` vs `SigA`）；TSS 坐标证据等级不同 | 同一来源内部比较；不跨来源并排比较；逐来源登记坐标证据类型 |
| C4 | 近同源序列造成验证泄漏 | 存在 3,430 对同源关系、1,169 条跨来源相同序列 | 划分按同源簇隔离，跨划分同源对为 0；跨来源重叠序列仅用于注释 |

## 3. 分析方法

### 3.1 总体分析流程

```text
数据获取与验收（甲）
    ↓
交接核验：SHA256 / 条数 / 配对不变式（乙独立复算）
    ↓
分组计数 → 质检与 GC / 长度 → 已知元件位置分布 → 背景校准 → σ 组间差异   ← 本报告范围（M2）
    ↓
de novo motif 发现（M3）→ FIMO 定位与已知元件对比 → 间距/排列分析 → 跨物种与跨数据集验证（M4）
```

### 3.2 序列窗口与坐标定义

| 项目 | 取值 |
| --- | --- |
| 窗口基准 | `local_tss_index = 61`（1-based，即转录起始位点位于序列内第 61 位） |
| 上游截取长度 | 60 bp |
| 下游截取长度 | 20 bp |
| 总长度 | 81 bp（22,594/22,594 全部相同） |
| 链方向处理 | 序列已统一为转录方向，**只扫描正向**，不扫描反向互补 |
| 坐标原点定义 | 偏移 = 序列内 1-based 下标 − 61；TSS 本身为 0，上游为负值 |
| 期望窗口 | -35 box：偏移 `[-37, -32]`；-10 box：偏移 `[-12, -7]`（沿用项目既有约定，对应序列内第 24–29 位与第 49–54 位） |

### 3.3 σ 因子分组策略

按 σ 因子类型分组，判定规则（沿用甲方清单，不重新评级）：

| 等级 | 判定条件 | 组数 | 分析层级 |
| --- | --- | ---: | --- |
| ✅ 可做正式结论 | 总数 ≥ 50 且 discovery ≥ 30 且 holdout ≥ 20 | 2 | 可报统计推断 |
| ⚠️ 只能探索 | 总数 20–49 | 8 | 可算，但结论须带探索性标记 |
| ❌ 只能描述 | 总数 < 20 | 9 | 只报 n / 均值 / 中位数，**不报 p 值、不报效应量** |

**σ 命名体系差异**：RegulonDB 用 `Sigma70` 形式，DBTBS 用 `SigA` 形式，跨来源比较前需先建立 sigma family 映射。本报告**不做跨来源并排比较**。

### 3.4 已知元件位置分布分析（仅 RegulonDB）

| 项目 | 设定 |
| --- | --- |
| 模板 | -35 box = `TTGACA`；-10 box = `TATAAT`（教科书已知元件，**不是**本项目自己发现的结果） |
| 主口径 | 精确匹配（0 错配） |
| 敏感性口径 | ≤1 错配（允许 1 个位置替换，6 聚体共 19 个模式串） |
| 扫描链向 | 仅正向 |
| 分析范围 | RegulonDB `core` 层，`discovery` 划分，n = 1,284 |
| 背景 | 数据自带的 `discovery.dinucleotide_null.fasta`，与正样本**逐文件配对**（n 同为 1,284，同长度，保持二核苷酸组成） |
| 加做分析 | 全窗口逐位置碱基组成与信息量（`info_vs_uniform`、`info_vs_null`），以及期望窗口内"实测最优碱基 vs 共识串"逐位比对 |
| 每条序列的代表命中 | 逐 σ 组位置统计时，**每条序列每个元件只取一个代表命中**（优先取落在期望窗口内的；否则取离窗口中心最近的一个），避免同序列多次偶然命中带偏均值 |

**关于背景选择的理由**：`natural_control`（label = 0）**不能当作无偏背景**。第 4.3 节量化显示，TJU 六物种的正样本 GC 全部低于同物种天然对照（中位数差 −4.938 至 −13.580 个百分点）。因此全部命中分析一律使用 `dinucleotide_null`。

### 3.5 GC 含量与序列长度分析（RegulonDB + DBTBS + TJU）

| 项目 | 设定 |
| --- | --- |
| GC 定义 | 整条 81 bp 窗口内 (G + C) / 81 × 100% |
| 分组维度 | 来源 × 物种 × 标签；σ 组（仅 RegulonDB core / DBTBS core 的 discovery 单标签序列）；TJU 正样本 vs 天然对照 |
| 展示形式 | 箱线图、密度图（`F1`、`F2`、`F3`） |
| 报告量 | 因分布很宽，**只报中位数与中位数差，不报均值差** |
| 背景自检 | 打乱对照与对应正样本的 GC 逐文件比对 |

**关于序列长度**：长度不是观测到的分布，而是构建时截取的固定窗口。22,594 条全部为 81 bp（均值 81、中位数 81、范围 [81, 81]、极差 0）。因此**长度维度的组间比较不适用**；长度图（`F10`）仅作留档，图上已标注"长度由窗口定义决定，不是观测到的分布"，不应被读作"长度高度保守"这一生物学发现。

### 3.6 统计方法与判定标准

| 项目 | 设定 |
| --- | --- |
| 连续量比较（GC） | Mann–Whitney U 检验 |
| 比例量比较（元件命中率） | Fisher 精确检验 |
| 效应量（连续量） | 中位数差 + bootstrap 95% 置信区间 + 秩双列相关 r |
| 效应量（比例量） | 风险差 + 95% 置信区间 + 比值比（OR） |
| 多重比较校正 | Benjamini–Hochberg，同时报告原始 p 与校正后 q |
| 显著性阈值 | q < 0.05 |
| bootstrap | 5,000 次，固定种子 `20261005`（`numpy.random.default_rng`） |
| 最小样本量门槛 | 总数 ≥ 50 且 discovery ≥ 30 且 holdout ≥ 20 |
| 统计用划分 | **仅 `discovery`**；`holdout` 未参与任何检验 |
| 比较范围 | **只在同一来源内部比较**（RegulonDB 内以 Sigma70 为参照，DBTBS 内以 SigA 为参照） |

**跨来源比较为何不做**：RegulonDB 是大肠杆菌、DBTBS 是枯草芽孢杆菌，物种不同、σ 命名体系不同、碱基组成也不同。直接比较会把**物种效应**当成 σ 效应。同理，SigA 的 -10 命中率（26.99%）与 Sigma70 的 -10 命中率（7.20%）**不得并排比较**。

### 3.7 降级规则

1. 未达最小样本量门槛的 σ 组，一律只报 n、均值、中位数，不做统计推断；
2. "不显著"一律表述为"样本量不足以判断"，**不表述为"没有差异"**；
3. 仅单来源支持、或跨来源不可比的结论，降级为描述性结果；
4. n ≤ 3 的组（SigM、SigI、SigL）不得作为任何结论的依据，引用其比例时必须标注 n。

## 5. 结论

### 5.1 已获得的结论

**（1）M1 阶段：数据构建与验收已完成，可支撑后续分析。**

本轮分析使用的数据版本为 `pr01_02_data_v2`，共 **22,594 条** 81 bp 启动子窗口序列，窗口相对 TSS 为 `[-60, +20]`，TSS 统一位于序列内第 61 位。其中正样本 13,953 条、天然对照 8,641 条（仅 TJU 六物种提供），来源共 8 个。数据完整性经甲、乙两方**独立**核对：210/210 文件 SHA256 一致、48/48 条数一致、79/79 打乱对照配对成立、6/6 汇总表行数一致，**交接核验通过**。

**（2）数据质量与适用范围。**

全部序列长度为 81 bp，无非法碱基字符，关键字段无缺失。同一（来源 × 划分）内仅发现 **1 对**完全重复序列（RegulonDB `core` 与 `extended` 两层含同一序列哈希），故按序列内容计 RegulonDB 唯一序列数为 3,812 而非 3,813。跨划分重复序列为 **0 条**，与 `cross_split_leakage_groups = 0` 一致。另有 **1,169 条**序列同时出现在两个来源中（RegulonDB↔TJU 大肠杆菌 760 条、DBTBS↔TJU 枯草芽孢杆菌 409 条），属同物种跨数据集重叠，**只能用于注释，不构成独立验证**。

**（3）RQ2（σ 因子类型间差异）：得到部分描述性结论，但受样本量严格限制。**

σ 因子标注仅存在于 RegulonDB 与 DBTBS，规范化后共 **19 个 σ 组**，合计覆盖 **1,498 条**单标签序列，**仅占全体数据的 6.63%**；其余 18,349 条 TJU 序列没有 σ 标签。按判定门槛，**仅 Sigma70（817 条）与 SigA（249 条）可作正式结论**，另有 8 组为探索级、9 组为描述级。

- **GC 含量**：RegulonDB 内，**Sigma32（n = 34）的 GC 中位数比 Sigma70（n = 583）高 3.09 个百分点**（95% CI [1.23, 6.17]，q = 0.0064，r = 0.293）；Sigma38 与 Sigma24 与 Sigma70 的中位数差为 0.00 个百分点（q = 0.8540）；Sigma54（n = 14）置信区间很宽（[−7.41, +6.79]），方向不明确。DBTBS 内，**SigB、SigE、SigG、SigK 的 GC 中位数分别比 SigA 高 6.17、4.94、5.56、6.17 个百分点**（q = 0.0034、0.0018、0.0014、0.0018，r = 0.413–0.493），方向一致、量级稳定，**但四组样本量仅 18–24 条，均属探索级**。
- **已知元件命中率**：RegulonDB 内各组 -10 命中率在数值上均低于 Sigma70（风险差 −3.63 至 −7.20 个百分点），但**校正后 q 值均 ≥ 0.6270**；-35 的比较 q 值全部为 1.0000。DBTBS 内 SigA 的 -10 命中率为 26.99%（44/163），其余各组 0–11.11%，但**校正后最小 q 值为 0.2862，均未达显著**。

**（4）已知元件的可检出程度：精确共识串罕见，但元件所在位置确有碱基偏好。**

以教科书元件为模板、在 RegulonDB `core` 的 `discovery` 划分（n = 1,284）中作精确匹配扫描：-35 box 命中 42/1,284（3.27%），配对打乱背景 33/1,284（2.57%），超出 +0.70 个百分点（95% CI [−0.60, +2.00]，p = 0.3485）；-10 box 命中 74/1,284（5.76%），背景 67/1,284（5.22%），超出 +0.55 个百分点（95% CI [−1.22, +2.31]，p = 0.6034）。**即：在精确匹配口径下，两个已知元件的命中率均未显著高于二核苷酸打乱背景。** 在允许 1 个错配的敏感性分析中，两者均显著高于背景（-35：+5.84 pp，p = 0.0029；-10：+8.72 pp，p = 1.06e−05），但**富集倍数仅为 1.16–1.17 倍**，属"弱但可测"。

这一结果与逐位置分析完全自洽：**-10 期望窗口内实测最优碱基为 `TAAAAT`，与共识 `TATAAT` 有 5/6 位一致**；**-35 窗口实测为 `TTTTTT`，与共识 `TTGACA` 仅 2/6 位一致**，表现为整段富 T。逐位置信息量在偏移 **−11** 取到全窗口最大值 0.221 bits（相对均匀分布），-10 窗口平均信息量 0.073 bits，约为 -35 窗口（0.026 bits）的 2.8 倍。**因此正确的表述是：已知元件所在的序列位置存在明确的碱基偏好（尤其是 -10 区），但精确的教科书共识串本身在真实启动子中较少出现。二者并不矛盾——共识串是各位置最常出现碱基的拼接，并不等于任何一条真实序列。**

**（5）位置分布（仅 RegulonDB）。**

两个元件的命中位置众数分别为偏移 −36（-35 box，7 次）与 −12（-10 box，17 次），恰好落在各自期望窗口的起点，可作为 TSS 对齐正确的旁证。-10 box 的命中中 92.2% 位于 TSS 上游，偏移 −14 至 −6 区间集中了全部命中的 67.5%。按 σ 组拆分后，**Sigma70 的 -10 位置中位数 −12.0、IQR 3.0**，集中度明显高于 **-35 位置（中位数 −35.0、IQR 29.0）**，后者分布右偏（均值 −24.76 与中位数相差 10 bp）。

**（6）间距分布（仅 RegulonDB）。**

精确匹配口径下全库仅 **1 对**有效配对，无法统计。≤1 错配口径下，Sigma70 有 97 对有效配对，**间距中位数 17.0 bp，与教科书值一致**（众数 18 bp），但 **Q1–Q3 为 10.0–24.0、SD 10.74，74.2%–77.3% 的个体落在 17±2 之外**。即"中位数对上了教科书，多数个体没有"。

### 5.3 对后续阶段（M3/M4）的输入

1. **输入口径已固化**：序列窗口 `[-60, +20]`、TSS 第 61 位、坐标偏移定义、仅扫正向序列、仅用 `discovery` 划分、背景一律使用 `dinucleotide_null`。这些参数写在脚本常量中，M3 应直接沿用，不得随结果调整。
2. **期望窗口已锁定**：-35 盒 `[-37, -32]`、-10 盒 `[-12, -7]`（沿用项目既有约定），M3/M4 的定位与对比应使用同一窗口。
3. **背景选择已确定**：因 TJU 正样本 GC 系统性低于天然对照（−4.938 至 −13.580 个百分点），`label = 0` **不可作为无偏背景**；M3 的 motif 发现必须使用打乱背景或更严格的对照设计。
4. **样本量边界已知**：按 σ 分组做 de novo 发现的可用样本上限是 1,498 条（discovery 1,059 条），其中仅 Sigma70 与 SigA 具备正式结论条件；这直接决定 M3 中"分组发现"的分组粒度。
5. **统计规范已建立**：连续量报中位数差 + bootstrap 95% CI + 秩双列相关；比例量报风险差 + 95% CI + 比值比；多重比较做 BH 校正；"不显著"须写作"样本量不足以判断"。
6. **可信度预警已量化**：精确共识串命中率低（3.27% / 5.76%）应作为 M3 方法选择的依据——**若 M3 只做固定串扫描，会得出"元件不存在"的误导结论**；必须采用允许变体的 profile 方法（PWM/一致序列比对）。
