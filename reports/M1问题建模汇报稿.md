# M1 问题建模汇报稿

我们的题目是 PR01-02 启动子调控模式发现。该项目不是启动子分类任务，而是一个带分组和独立验证的无监督序列模式发现问题。

输入是对齐到 TSS 的多物种启动子序列，以及物种、σ 因子类型、数据来源和证据等级等元数据。核心输出包括 motif 的 PWM 表示、每条序列上的命中位置、motif 之间的间距和排列，以及这些模式在不同 σ 因子、物种和数据集中的复现情况。

我们将三个研究问题分别转化为三个可计算任务：第一，比较 de novo motif 与 `-10/-35 box` 等已知元件的 PWM 相似性、位置重合和恢复效果；第二，比较不同 σ 因子组的 motif 出现率、位置和间距分布；第三，通过隔离发现集和验证集，检验 motif 的跨物种、跨数据集复现率和稳定性。

模型体系分为五层：B0 是已实现的已知核心元件 PWM 扫描；B1 是全体序列 MEME；B2 是 STREME/DREME 短 motif 对照；B3 是按 σ 因子分组发现；B4 是按物种和数据源独立重复发现。同时设置保持碱基组成的随机背景，检查假阳性。

评测不使用单一指标，而是同时报告 motif 相似性、FIMO q-value、出现率和效应量、位置与间距分布、跨来源复现率和重采样稳定性。所有多重比较使用 FDR 校正，并严格区分“计算候选新 motif”和“已验证的新生物学元件”。

当前已经完成数据标准化、质量过滤、去重、发现/验证标记、背景构造、EDA 和 B0 PWM 基线。下一步接入真实 RegulonDB/DBTBS 数据，锁定 TSS 窗口和分组，再运行 MEME、FIMO 和跨数据集验证。现阶段可以确认问题建模和实验方案已经闭合，但还没有真实数据结论。
