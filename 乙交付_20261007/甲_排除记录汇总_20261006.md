## 5. 各原因的含义

| 原因 | 含义 |
| --- | --- |
| `multiple_or_conflicting_TSS_marks` | DBTBS 网页上有多个粗体 TSS 标记互相冲突，无法确定使用哪一个 |
| `Location_ND_or_unresolved` | 网页 `Location` 字段为 `ND`（未确定），或坐标格式无法解析 |
| `missing_or_invalid_sequence_TSS` | RegulonDB 原始记录序列为空，或 TSS 字段无效 |
| `inconsistent_location_endpoints` | 相对位置、绝对位置、实际序列长度三者对不上 |
| `invalid_81nt_ACGT` | 长度非 81 bp，或含 A/C/G/T 以外的字符（4 条均为 80 bp 负样本） |
| `split_record_conflict` | 原始 train/dev/test 拆分中同一条序列被标了互相冲突的标签 |
| `reference_window_mismatch` | 从参考基因组提取的窗口与记录不一致（旧审计中的 `ygiWp6`） |
