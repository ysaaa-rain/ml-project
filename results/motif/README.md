# motif 结果目录约定

本目录只保存经过检查、可用于课程报告或答辩的小型最终产物，例如 motif 矩阵、motif 摘要表、统计表、图表和运行 manifest。每个正式实验都必须记录输入/配置/软件版本/完整命令、随机种子（如适用）、SHA256、样本量和已知限制。当前 M3 的 MEME 概率矩阵、Tomtom 初比摘要和 manifest 已在本地 `m3_20260930/` 生成，并与[M3 阶段报告](../../reports/M3阶段报告.md)对应。

原始 FASTA、下载数据、完整 MEME HTML/XML、临时日志、重复中间文件、大型 embedding 和模型权重不放在这里。MEME 原始运行目录应放到被忽略的 `tmp/` 工作目录；审查后只将必要的小型结果复制到本目录。加入 Git 前检查每个文件的内容、来源许可、是否包含可再分发的原始序列片段以及文件大小。

报告引用的正式结果原则上应能在本目录直接找到；若完整产物因体积或许可不能入库，应提交摘要、来源/获取方式、大小、SHA256 和可复现命令作为索引。TJU Pan 六物种 CSV 已与 PromLoop 固定提交逐文件核验一致，本目录只纳入对应的报告级 motif 矩阵、图表和聚合统计；原始序列及逐条命中仍不提交。RegulonDB 衍生 motif 结果的公开许可仍待核验，继续只留在本地工作树。此处的 `.gitignore` 例外仅允许 Git 跟踪文件，不等于任何来源的许可自动通过。
