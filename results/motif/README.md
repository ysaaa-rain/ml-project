# motif 结果目录约定

本目录保存已核验、用于课程报告和复现的实验产物：motif 矩阵、汇总表、统计表、图表和运行 manifest。正式实验的代码、报告与这些结果一并纳入 Git。每个实验记录输入哈希、工具版本、参数、样本量和结果哈希。

原始 FASTA、下载数据、完整 MEME HTML/XML、临时日志、重复中间文件、大型 embedding 和模型权重不放在这里。MEME 原始运行目录应放到被忽略的 `tmp/` 工作目录；审查后只将必要的小型结果复制到本目录。加入 Git 前检查每个文件的内容、来源许可、是否包含可再分发的原始序列片段以及文件大小。

报告引用的正式结果可在本目录直接找到。若完整产物因体积或许可不能入库，则在此保留摘要、来源/获取方式、大小、SHA256 和复现命令。TJU Pan 六物种 CSV 已与 PromLoop 固定提交逐文件核验一致；此处收录其报告级 motif 矩阵、图表和聚合统计。RegulonDB 结果用于辅助 σ 分组分析，收录 motif 矩阵和聚合统计。原始数据、序列 FASTA、逐序列 FIMO 命中、完整 MEME XML/HTML、日志和缓存保留在仓库内忽略的 `data/`、`tmp/` 子目录，不随 Git 提交。
