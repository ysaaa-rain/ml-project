# EDA 正式结果目录约定

本目录只保存经过核对、能直接支持项目报告与阶段汇报的聚合表格和图表。不得存放原始启动子序列、逐样本元数据、完整命中明细、随机背景序列、大型中间文件或未经许可审核的数据副本。

每个结果子目录需有一份说明或 manifest，记录来源与版本、输入 SHA256、配置/代码版本、环境、完整命令、样本数、主要结果、限制和产物 SHA256。原始下载、清洗表、FASTA、全量 hit 明细与临时运行日志留在 `.gitignore` 覆盖的 `data/` 或 `tmp/`；报告引用的聚合数字和图表应能在此处找到。

`.gitignore` 允许本目录中的文件被 Git 跟踪，不代表自动提交，也不代表来源许可已经通过。每次加入前仍需检查内容、许可、隐私/再分发边界和文件大小。
