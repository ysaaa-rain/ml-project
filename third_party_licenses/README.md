# 第三方来源与许可说明

## PromLoop 六物种 promoter 数据

本项目六物种 reg_and_gen/Datasets CSV 与 [KevinHZS/PromLoop](https://github.com/KevinHZS/PromLoop) 固定提交 747d84e67be337178d75c403c099581de4ee86c9 中相应文件逐一 SHA256 完全一致。该上游提交根目录声明 Apache License 2.0；许可证副本见本目录 PromLoop-Apache-2.0.txt。逐文件核验记录见[数据与上游文件哈希核验](../docs/PromLoop数据来源哈希核验_20261003.md)。

本仓库没有重新分发原始序列 CSV/FASTA，而是提供 PR01-02 分析代码、汇总结果与可视化。云盘 strenth、补充材料及其他文件不在上述核验和许可说明范围内。
