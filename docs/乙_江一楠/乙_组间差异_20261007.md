# 乙 - σ 组间差异（步骤 6）

日期：2026-10-07
数据版本：`data/processed/pr01_02_data_v2/`
范围：**RegulonDB `core` + DBTBS `core`，单标签 σ 序列，只用 `discovery` 划分，共 1,059 条**（19 组；全划分合计 1,498 条）
证据表：`乙_产出/tables/T16_GC组间比较_vs参照组.tsv`、`T17_元件命中率组间比较_vs参照组.tsv`、`T18_sigma组描述统计_发现集.tsv`

脚本：`乙_analysis/scripts/05_group_diff.py`

## 0. 问答记录对这一步的硬要求

> "比不同向导组的差别，用合适的统计方法，**必须报'差多少'不能只报'显著不显著'**。"

所以本文件每一行都有**效应量 + 置信区间**，p 值只是附带。

---

## 1. 口径（为什么这么比）

| # | 规则 | 理由 |
| --- | --- | --- |
| 1 | **只在同一来源内部比** | RegulonDB（大肠杆菌）和 DBTBS（枯草芽孢杆菌）**物种不同、σ 命名体系也不同**（`Sigma70` vs `SigA`），直接比会把物种效应当成 σ 效应。见 [甲_σ组可用性清单_20261006.md](../甲_Nj123421/甲_σ组可用性清单_20261006.md) 口径说明 2 |
| 2 | 参照组：RegulonDB 内用 **Sigma70**（n=583）、DBTBS 内用 **SigA**（n=163） | 各自来源里样本量最大、且是"主 σ" |
| 3 | 只用 `discovery` | `holdout` 一律不碰 |
| 4 | 只用 `core` 层单标签序列 | 与 `sigma_group_summary.tsv` 口径一致 |
| 5 | **"只能描述"的组不报 p 值、不报效应量** | 甲的口径："只报样本量，不做统计" |
| 6 | 连续量（GC）报**中位数差 + bootstrap 95%CI + 秩双列相关 r** | 分布很宽，均值不可靠 |
| 7 | 比例量（命中率）报**风险差 + 95%CI + 比值比** | 直接回答"差几个百分点" |
| 8 | 多重比较做 BH 校正，同时给 p 与 q | 一次比较十几个组 |

**样本量的现实**：19 个 σ 组里，`discovery` 划分超过 30 条的只有
Sigma70（583）、SigA（163）、Sigma38（84）、Sigma24（45）、Sigma32（34）**五组**。
其余 14 组的 discovery 样本都在 24 条以下。**这是本节所有结论的硬约束。**

**只描述**：**只有 Sigma32 的 GC 显著高于 Sigma70，差 +3.09 个百分点（q = 0.0064）**，

**只描述**：**DBTBS 里 4 个可检验的 σ 组，GC 中位数全部高于主 σ SigA，

且都属于"只能探索"级别——**方向一致不等于可以下正式结论**。

## 5. 本节的结论边界（丙必读）

| 可以写 | 不可以写 |
| --- | --- |
| "RegulonDB 内 Sigma32 的 GC 中位数比 Sigma70 高 3.09 个百分点（95%CI 1.23–6.17，q=0.0064）" | "Sigma32 的启动子 GC 更高"（这涉及机制，M2 不做） |
| "DBTBS 内 SigB/SigE/SigG/SigK 的 GC 中位数比 SigA 高 4.9–6.2 个百分点，q<0.005" | "σ 类型决定 GC 含量" |
| "RegulonDB 内各组 -10 命中率数值上都低于 Sigma70，但校正后均不显著" | "非主 σ 组缺乏 -10 元件" |
| "SigA 的 -10 命中率 26.99% 与 Sigma70 的 7.20% 不可直接比较（物种不同）" | "枯草芽孢杆菌的 -10 元件比大肠杆菌强" |
| "SigM 命中率 100.00%（1/1）是抽样噪声" | 任何以 SigM / SigI / SigL 为依据的结论 |

**三条最容易被过度解读的地方，请丙务必盯住：**

1. **"只能探索"的组（8 个）不是"可以用但要小心"，而是"可以用但结论必须带探索性标记"**，
   而且它们的 discovery 样本大多在 14–24 条之间。
2. **跨来源的数字不能并排比较**。Sigma70（大肠杆菌）和 SigA（枯草芽孢杆菌）
   在报告里可以各自陈述，但**不能写成"σ70 与 σA 的对比"**。
3. **"不显著"要写成"样本量不足以判断"，不能写成"没有差异"**——
   因为很多组的置信区间很宽（例如 Sigma54 的 GC 差 CI 是 [−7.41, +6.79]）。
