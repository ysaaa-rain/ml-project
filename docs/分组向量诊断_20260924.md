# RegulonDB TSS 子集分组向量诊断

日期：2026-09-24

## 本轮做了什么

在 Gate A 已确认的 RegulonDB 来源内 TSS 对齐子集上，对 3,807 条统一长度为 81 bp 的启动子序列提取冻结模型向量，并检查聚类与 sigma 标签、证据等级、GC 含量和最近邻的一致关系。

模型为 `InstaDeepAI/nucleotide-transformer-v2-50m-multi-species`，revision 固定为 `f1ff02bacb08d292ee9c3e227356d692055ac50d`；使用 mean pooling、CPU、batch size 4 和随机种子 `20260924`。输入配置为 [`l0_embedding_regulondb_tss_20260924.yaml`](../configs/l0_embedding_regulondb_tss_20260924.yaml)。

| 项目 | 结果 |
| --- | ---: |
| TSS 对齐输入 | 3,807 条，全部为 81 bp |
| 向量形状 | `3807×512` |
| KMeans 聚类数 | 3 |
| silhouette | 0.03453 |
| sigma 与聚类 ARI / NMI | 0.00014 / 0.00207 |
| evidence level 与聚类 ARI / NMI | -0.00027 / 0.00012 |
| 5-NN 关系总数 | 19,035 |
| 两端 sigma 均已知的近邻关系 | 13,257 |
| 已知 sigma 近邻同组比例 | 41.69% |
| 由组别频率得到的随机配对基线 | 41.70% |
| GC 与 PCA 第 2 轴 Spearman 相关 | -0.1713 |

已知 sigma 的样本量分别为 Sigma70 1,942、Sigma24 513、Sigma32 300、Sigma38 176、Sigma28 140、Sigma54 96；另有 640 条 sigma 未知记录。随机基线按已知标签序列的组别频数计算，即从这些记录中随机抽取两条不同序列时同组的期望比例。

## 当前解释

本轮的聚类 silhouette 较低，聚类与 sigma 标签的 ARI/NMI 接近零。近邻中的已知 sigma 同组比例与随机配对基线几乎相同。因此，当前结果没有显示模型向量按 sigma 因子形成清晰分组。序列长度全部为 81 bp，长度相关性在本数据中无法估计；GC 与 PCA 第 2 轴存在一定相关，后续比较仍需关注组成影响。

输入只来自 E. coli 的 RegulonDB，且全部属于 discovery。source、species 和 split 在本子集中没有可供比较的组别，因此本轮不回答跨来源或跨物种复现，也不形成生物学结论。
