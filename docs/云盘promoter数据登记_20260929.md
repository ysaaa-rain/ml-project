## reg_and_gen 主数据输入核验

六物种完整数据共 18,370 行，其中正类 9,724 条、负类 8,646 条。六份 positive_samples.csv 均已逐条与 Dataset.csv 中 label=1 核对。所有正类均为 81 bp、仅含 A/C/G/T。M3 正类按物种分别输入 MEME，label=0 中长度有效的负类作为真实数据背景。

| 物种目录 | 总记录 | 正类 | 原始负类 | 有效 81 bp 负类对照 | 输入问题 |
| --- | ---: | ---: | ---: | ---: | --- |
| Bacillus_subtilis | 1,500 | 691 | 809 | 809 | 无 80 bp 对照 |
| Baumanii | 2,900 | 1,540 | 1,360 | 1,360 | 无 80 bp 对照 |
| Bradyrhizobium | 3,940 | 1,987 | 1,953 | 1,952 | seq_id 3565 有一条 80 bp 负类；4 条正类重复记录 |
| Diphtheria | 3,310 | 1,654 | 1,656 | 1,655 | seq_id 32 有一条 80 bp 负类 |
| Escherichia_coli | 3,350 | 1,645 | 1,705 | 1,704 | seq_id 2444 有一条 80 bp 负类；8 条正类重复记录 |
| Staphylococcus | 3,370 | 2,207 | 1,163 | 1,162 | seq_id 3357 有一条 80 bp 负类；1 条正类重复记录 |

正类重复记录保留，不对原始样本静默去重；计算 motif 覆盖率时同时报告记录数和唯一序列数。train/dev/test 间 exact duplicate 检测在 Bradyrhizobium 与 E. coli 分别发现 2 条和 3 条相同序列。它们不是独立数据集，后续跨数据集验证还需单独比较两个来源间的序列重叠及高相似关系。

## 关键字段与坐标边界

云盘 CSV 没有 sigma 因子、genome coordinate 或 strand 列。上游说明将窗口描述为 81 bp、相对 TSS −60 至 +20，但云盘文件本身不能证明所有负链是否统一到转录方向。因此：

- 可以先对每条序列报告 1–81 的序列内 motif 坐标；
- 方向核验前不能给这些命中标注为 TSS 上游/下游；
- 六物种云盘数据本身不能承担 σ 分组分析；该问题由有标签的 RegulonDB 辅助数据支持；
- 六个物种来自同一云盘数据体系，可用于跨物种比较，但不能把同一发布体系内的拆分说成独立跨数据集复现。

## 输入生成和审计文件

六物种 FASTA 由 experiments/prepare_tjupan_motif_inputs.py 生成，当前命令为：

~~~bash
python -m experiments.prepare_tjupan_motif_inputs
~~~

参数包括每物种正类 FASTA、label=0 对照 FASTA、样本数、原始 CSV 哈希、FASTA 哈希、重复计数、拆分记录计数和异常长度 ID。公开 manifest 不包含实际 DNA 序列；完整 FASTA 留在 tmp/ 下。本地结果清单为 results/motif/tjupan_m3_20261003/input_manifest.json。
