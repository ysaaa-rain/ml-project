# M1/M2 问答记录（2026-10-05）

 供组内对齐使用。 

# 一、这个实验到底在干啥

细菌的 DNA 是一栋大楼，每个房间里放着一张配方（基因），门口挂着一块牌子写着"从这里开始念"（启动子）。楼里有个工人（RNA 聚合酶）负责进房间干活，但他**不认路**，每次都得有个**向导**（sigma 因子）牵着他走到正确的门口。

向导不是只有一个，是一整队。平时用"日常向导"，遇到高温、挨饿、要变孢子就换别的向导，换向导就等于换一批被打开的房间。

**我们要干的事就一句：把一大堆门口牌子收集起来，按"是哪个向导带去的"分成几堆，看每一堆牌子上的暗号写得一样不一样。**

具体看四件事：暗号写的是什么（写法）、出现在牌子的什么位置、两个暗号之间隔多远、哪些暗号总是一起出现。

最后还要回答一个很关键的问题：**这些规律换一批牌子、换一栋楼还成立吗？** 不成立的话，前面看到的东西可能只是碰巧。

# 二、M1 到 M5 是啥（阶段）

M 是**时间轴**，是老师按时间点检查你们进度的五个节点。

| 阶段 | 大白话 | 产出 |
| --- | --- | --- |
| M1 | 备料：把数据收集来、洗干净、统一格式、按向导分组 | 一张干净的标准表 |
| M2 | 摸底：对着数据量一量画一画，先看看它长什么样 | 图、表、描述性结论 |
| M3 | 第一次找暗号，形成初步结果（中期汇报） | 第一版暗号列表 |
| M4 | 完整实验：看暗号在哪儿、隔多远、换数据还成不成立 | 完整结果 |
| M5 | 收口：写报告、做图、准备答辩 | 最终交付 |

**你们三个人现在负责的就是 M1 和 M2**，也就是"备料"和"摸底"，七个实验一个都还没轮到你们。

# 三、七个实验是啥（内容）

实验 1–5 是老老实实的生物信息学分析，实验 6–7 才是机器学习。它们主要落在 M3 和 M4 里。

| 实验 | 大白话 |
| --- | --- |
| **1 找暗号** | 把牌子按"物种 + 向导"分组，每组单独找反复出现的小短句。每组数量多的用 STREME，数量少的用 MEME，少于 10 条的组不做正式分析 |
| **2 看位置** | 拿第 1 步找到的暗号当模板，去每条牌子上扫一遍，看它出现在离"从这里开始"多远的地方 |
| **3 对答案** | 把找到的暗号拿去跟科学家早就知道的那几个（-10 box、-35 box、UP 元件）比一比，看能不能对上 |
| **4 比语法** | 不同向导的牌子，暗号写法、出现频率、位置、两个暗号之间隔多远、谁在前谁在后、哪些总一起出现——是不是不一样 |
| **5 换地方验证** | 用一批**没参与找暗号**的牌子，再换一个数据库、换一个物种各验一次。这一步决定前面看到的规律能不能信 |
| **6 机器学习当裁判** | 把前面找到的暗号变成一串数字，训练模型猜"这是哪个向导的牌子"。重点**不是猜得多准**，而是看"加上位置信息、再加上间距信息，分别多提升多少"——用这个证明位置和间距真的有用 |
| **7 机器学习自己找** | 不给它任何暗号，直接把原始序列喂给神经网络，让它自己学，再用解释工具把它学到的关键片段抠出来，转成暗号，最后跟第 1 步找到的、以及已知库的互相印证 |

注意一个顺序问题：**第 6、7 个实验不是用来替代前五个的**，它们是来验证"前面找到的东西到底是真规律还是描述性现象"，以及"机器能不能独立找到同样的东西"。

# 四、数据分工是啥

一共四个来源，但角色完全不同，这是最容易搞混的地方。

| 来源 | 是什么 | 干什么用 | 为什么这么分 |
| --- | --- | --- | --- |
| **RegulonDB** | 大肠杆菌官方数据库 | **主力：拿来找暗号** | 它带"从哪开始"（TSS）和"哪个向导"（sigma）标签，是唯一能算出位置和间距的 |
| **DBTBS** | 枯草芽孢杆菌官方数据库 | 也拿来找暗号，但**做不了位置分析** | 它没有可靠的"从哪开始"和链方向，位置只能空着写"无" |
| **TJU 云盘六物种** | 老师给的云盘数据 | **换地方验证用**，不能再拿来找暗号 | 它没有 sigma 标签，也没坐标。而且用它找过暗号后，就不能再拿它说"我验证成功了"——等于提前看了答案 |
| **strenth 子目录** | 云盘里的启动子强度数据 | 暂时搁置 | 单位、实验条件都没搞清楚 |

**一句话记住**：RegulonDB 和 DBTBS 负责"找"，TJU 云盘负责"验"，两边的活不能混。

这也是为什么要特别小心——**找规律的数据和检验的数据必须分开**。用同一批数据找完规律再拿它验证，等于考试前看了答案，说服力等于零。

1. **M1–M5 是阶段（什么时候做），实验 1–7 是内容（做什么），两套编号别混。**
2. **实验 1–5 是传统分析，6–7 是机器学习，前面不成立后面就不用做。**
3. **RegulonDB/DBTBS 用来找，TJU 云盘用来验，你们三个人现在干的是 M1/M2（备料和摸底）。**

## 三个人的活

| 谁 | 干什么 | 交出什么 |
| --- | --- | --- |
| **甲：管数据的** | 把数据弄到手，核对数量对不对，洗干净，写清楚每个字段啥意思，再把 DBTBS 那 698 条逐条看一遍证据 | 干净的数据表 + 字段说明书 + DBTBS 证据表 |
| **乙：算数字画图的** | 数每组有多少条、算 GC 和长度、看 -10/-35 出现在哪儿、比不同向导之间的差别，然后画成图 | 一堆表 + 一堆图 + 一段"我们看到了什么" |
| **丙：写报告盯数字的** | 写 M1/M2 报告，核对报告里每个数字都能在表里找到，登记用了哪些文件，做汇报页 | 正式报告 + 数字核对表 + 汇报页 |

## 每个人具体干啥（大白话）

**甲：**

1. 先把数据找齐。现在这台电脑上一个数据文件都没有，得从队长那儿要，或者自己重新下载。
2. 拿到手先数数：是不是 3,822 个位置、1,100 条好数据、训练 751、留出 349。数对不上就说明拿到的不是同一版，得问清楚。
3. 写一份"字段说明书"：表里每一列是什么意思、单位是什么、空着代表什么。**这份东西是乙的命根子**，乙要靠它判断哪些数据能用、哪些不能用。
4. 把 DBTBS 那 698 条一个个看：原始文献里到底怎么做的实验、够不够格当可靠数据、有没有写"从哪里开始"。大概率大部分都没有，那就老实写"没有"，不要猜。

**乙：**

1. 先数人头：每个物种、每个向导、训练集和留出集各有多少条。这一步会决定后面哪些能分析——比如 Sigma28 只有 8 条，那就是"太少了，只能描述不能下结论"。
2. 算 GC 含量、序列长度、有没有缺失，按物种和向导分组，画成图。
3. 看 -10 box、-35 box 出现在什么位置。**这是这次唯一能做对的地方**，因为 RegulonDB 的数据带真实起点，能算出"在起点上游多少 bp"这种有生物学意义的坐标。
4. 但**必须先跑一次"背景校准"**——用随机打乱的序列扫一遍，看看有多少命中是纯靠运气撞上的。旧数据里这个比例是 14.5%，新数据得重新算。
5. 比不同向导组的差别，用合适的统计方法，**必须报"差多少"不能只报"显著不显著"**。
6. 最后写一段话总结，但只能写"X 组 GC 中位数是 A，Y 组是 B"，**不能写"发现了新暗号"**——找暗号不是 M2 的活。

**丙：**

1. 队友之前写过一份 M1/M2 报告，但里面全是"预期""假设"，没有真实数字。丙的活就是把它换成有真数字的结果稿。
2. 做一张核对表：报告里每个数字，都能指到"哪个文件、哪一行"。挑两三个自己重算一遍，对不上就打回去重做。
3. 登记清楚：用了哪些文件、什么参数、什么软件版本、什么时候跑的。这套东西叫 manifest，就是一份"我干活的完整台账"。
4. 做一页汇报，让队长一眼看懂：做了什么、数据多少条、看到什么、哪些不能下结论。

## 三条谁都不能碰的线

**第一，缺的数据就写"没有"，不许猜。** DBTBS 没有"从哪里开始"和链方向，位置一格都不能填。猜一个数字比空着严重得多。

**第三，每个数字都要有出处。** 图好看不算数，能追到文件才算数。

## 问题三

**问：** 所以我们到底要分析哪一个数据？

**答：**

直接回答：**按仓库现在生效的规矩（10 月 4 日那份新规范），你们 M1/M2 要分析的是 RegulonDB 和 DBTBS，不是云盘那六个物种。**

三个数据的分工是这样的：

| 数据 | 你们要不要分析 | 能分析什么 |
| --- | --- | --- |
| **RegulonDB**（大肠杆菌） | **要，这是主力** | 全部都能做：GC、长度、-10/-35 box 位置、按 sigma 分组比较 |
| **DBTBS**（枯草芽孢杆菌） | **要，但只能做一半** | 只能做 GC、长度这种跟位置无关的；**位置分析一格都不能碰**，因为它没有可靠的"起点"和链方向 |
| **TJU 云盘六物种** | **不要，留着后面验证用** | 它没有 sigma 标签、没有坐标，做不了你们要的分组和位置分析 |

## 为什么是 RegulonDB 而不是云盘

回想一下你们的任务：**按 sigma 因子类型分组，分析 -10/-35 box 的位置分布。**

这两件事都要求数据里必须有 **"哪个向导认领的"（sigma 标签）** 和 **"从这里开始"（TSS 坐标）** 这两样东西。

- RegulonDB：两样都有 ✅
- DBTBS：有 sigma，没坐标 ⚠️
- 云盘六物种：两样都没有 ❌

云盘数据只有"一段序列 + 是不是启动子"这两列信息。它没法按 sigma 分组，也定位不了位置。**所以你们的核心任务在云盘数据上根本做不了。**

## 具体分析多少条

RegulonDB 重建之后的数据是这样：

- 3,822 个位点（一条序列一个位置）
- 其中 1,100 条算高质量，是 Gold 代表
- 分成训练 751 条、留出 349 条
- 六个 sigma 组，其中 Sigma70 最多（588 条训练），Sigma28 最少（8 条训练）

**M2 的统计主要用训练那 751 条**，留出的 349 条留着后面验证用，你们不能拿它调参数。

Sigma28 只有 8 条，按规矩属于"样本太少，只能描述不能统计"，写报告时要单独标出来。

## 问题一

**问：** 这7个实验不是我们数据分析应该干的事情是吗？

**答：**

对，**你们现在要干的不是那 7 个实验**。 :codex-annotation{index="1"}

但这里有个词要小心：**"数据分析"这四个字把两件事混在一起了。**

M2 本身就是数据分析——只不过它是**描述性的**数据分析：量一量数据长什么样、画图、算个中位数、比比组间差异。它不叫"实验"，因为它不检验任何科学假设，只是摸清家底。

那 7 个实验是**研究性**的实验：要用 MEME/STREME 找暗号、用 FIMO 定位、要控制 q 值、要做消融、要训练模型。这些东西要严谨的实验设计，不是"看一眼数据"。

对照一下就很清楚：

| 你们的活（M1/M2） | 那 7 个实验的活 |
| --- | --- |
| 收数据、洗数据、统一格式 | 用工具找新暗号 |
| 按向导分组、划分数据 | 跟已知库对答案 |
| 算 GC、长度、看缺失 | 统计间距、共现 |
| 画分布图、算中位数 | 换物种做验证 |
| 写"我们观察到 X 组 GC 偏高" | 训练模型、算消融 |
| 用现成软件就够（pandas + 画图） | 需要 MEME Suite、PyTorch 等专门环境 |

**为什么这么分？** 因为你们是地基，他们是楼。地基没打好，上面盖的全要返工——你们仓库 10 月 4 日刚吃过这个亏：之前跑的 MEME、FIMO 出来一堆结果，后来发现坐标处理错了，整批作废。

**还有一个特别容易搞混的点，你们做 M2 时会撞上：**

M2 里确实要分析 -10 box、-35 box 的位置分布。听起来很像实验 2（定位）。但两者完全不同：

- **M2 的做法**：拿教科书上早就写好的 `TTGACA`、`TATAAT` 这两串固定字母，在序列里扫一遍，看它们出现在哪儿。用的是**已知答案**，只是描述现象。
- **实验 2 的做法**：拿实验 1 自己**从数据里发现**的暗号，再回来定位，还要控制统计显著性、区分严格位点和候选位点。

所以你们做 M2 的时候，如果有人问"你们是不是在做实验 2"，答案是：不是，我们用现成的已知元件，只是看分布。

**最后一个实际问题：你们什么时候可能接到那 7 个实验？**

看队长安排。常见的情况是：M1/M2 做完、数据冻结了，队长再按人头分后面的实验。但有个硬规矩：**谁做"找规律"的部分，就不能同时拿同一批数据去做"验证"**——否则等于提前泄题。

所以如果队长之后让你们接某个实验，先问清楚两件事：这批数据是发现集还是验证集？之前有没有人用它做过发现？
