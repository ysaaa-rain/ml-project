# PR01-02：项目任务与阶段边界

更新：2026-10-08。本文件只确定任务定义；数据/运行细则在 [现行文档导航](README.md)。

## 项目目标与 RQ（贯穿全项目）

- **RQ1**：从细菌启动子发现哪些序列 motif？与可靠已知 −10/−35、UP 元件、TFBS 有何相似性、位置关系与新的候选？
- **RQ2**：不同 σ 因子类型的启动子在 motif 组成、位置、间距/排列上有什么差别？仅在有 σ 注释且样本量允许时作分组推断。
- **RQ3**：motif 是否在同来源留出、不同物种、去重叠的独立来源中具有可复现性？三种验证不得混报。

## 老师的课程阶段（不同于 RQ）

- **M1：问题定义与数据构建。** 采集多物种启动子，查明三个数据来源的真实性、数量、样本标签、TSS/序列方向、σ 关联和可比性；按 σ 类型分组，提交**数据说明、规模/覆盖/限制、结论和证据**。本阶段不运行 de novo motif 发现。
- **M2：探索性数据分析。** 只读查看和统计 M1 数据的序列长度、GC、−10/−35 既有共识序列在 TSS 对齐窗口的初步位置与间距、各 σ 类型样本量/差异。应当回答“看到了什么、哪些组可比较、哪些结论不能推出”，提交表、图、文字结论与复算线索。**不要求为 M2 跑 MEME/STREME/DREME/FIMO，也不做算法消融/方法对比。**
- **M3：motif discovery。** 采用 TJU 六物种 v2 discovery 进行 STREME 主发现（天然负样本与 dinucleotide shuffle 两轮独立对照）。后续按预注册确定 MEME 方法互证。
- **M4 及后续：** 固定 PWM 后 FIMO 位置/间距/共现、已知元素参考匹配，分层留出验证、跨物种比较、课程规定的其它实验或扩展。

**研究问题与课程阶段是两个维度：** M1/M2 可以提供 RQ1/RQ2/RQ3 的数据背景，但不能把描述性共识串命中率当成已通过正式 motif discovery 和独立验证。

## 数据和统计边界

TJU/PromLoop 六物种是主序列；RegulonDB E. coli 用作 σ 专项和严格去重叠的来源验证；DBTBS B. subtilis 的 432 条核心与 TJU 高度重叠，只作 σ、TSS/位置、文献的补充注释/描述，**不作独立外部统计验证**。TJU 81bp 序列采用已发布 TSS 对齐与方向，不声称逐条基因组独立核验。正式分析不读 `positive_samples.csv`，其原始文件保留。v2 已处理 exact/RC 重复与编辑距离≤8 的关联组隔离，未发现当前阈值下跨 discovery/validation 相关序列。

M1/M2 的数据摸底可以描述全量分布并明确分母；**由数据决定新假设或调阈值的步骤不可提前利用未来 STREME 的 holdout**。正式统计、序列来源及工具版本写清；无数据处写待补，不以传统共识模板匹配替代 de novo 发现。
