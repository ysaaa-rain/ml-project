## 2. 项目主题和动机（课程要求）

启动子的 \`-10/-35 box\` 是核心调控元件。不同物种、不同 sigma 因子类型的启动子在核心元件之外，还可能包含 UP element、抑制子结合位点、激活子结合位点等辅助元件。这些元件的组成、位置和排列共同影响启动子的调控特异性与强度。

本项目从多物种启动子序列中系统发现：

- 核心 motif 的变异谱；
- 辅助 motif 的出现频率；
- motif/元件之间的间距分布和排列模式；
- 不同物种、sigma 因子类型和数据集之间的共性与差异。

项目的核心挑战是判断发现的模式是否具有统计显著性，以及是否能在跨物种、跨数据集验证中保持一致。

## 3. 研究问题（RQ）

- **RQ1：** 从多物种启动子序列中发现的 de novo motif，与已知核心元件（\`-10/-35 box\`、UP element）和辅助调控元件的重合度如何？是否存在新 motif？
- **RQ2：** 不同 sigma 因子类型的启动子在 motif 组成和间距分布上有何差异？是否存在类型特异的调控模式？
- **RQ3：** 发现的调控模式在跨物种和跨数据集上是否一致？哪些模式是通用的，哪些是物种或数据集特异的？

所有最终结论必须逐条回答 RQ1-RQ3，并由可复现实验结果支撑。

## 4. 总目标和阶段任务

### 4.1 总目标

从多物种启动子序列中发现调控 motif 和间距模式，与已知元件进行比较，分析跨物种和跨类型一致性，并通过额外的 motif-强度关联和 motif 组合分析提高项目完成度。

### 4.2 课程规定的阶段任务

1. **问题定义与数据构建（M1）**：采集多物种启动子序列，按 sigma 因子类型分组。
2. **探索性数据分析（M2）**：分析 \`-10/-35 box\` 位置分布、GC 含量和类型间差异。
3. **Motif 发现（M3）**：使用 MEME/DREME 对全序列和分组序列发现 motif。
4. **间距和排列分析（M4）**：分析 motif 间间距分布和排列顺序。
5. **跨物种和数据集验证（M4）**：在不同物种和数据集上重复发现并计算一致性。
6. **总结（M5）**：回答 RQ1-RQ3。

## 5. 方法范围

课程建议方法及其在本项目中的用途如下：

| 方法 | 项目用途 | 是否主线 |
| --- | --- | --- |
| MEME | 中小规模序列的 de novo motif 发现 | 是 |
| DREME/STREME | 短 motif、较大样本或富集 motif 发现 | 是，作为对照/补充 |
| FIMO | 在序列中定位已发现或已知 motif | 是 |
| PWM/共识序列 | 表示已知 \`-10/-35 box\`、UP element 和发现 motif | 是 |
| 统计检验与多重校正 | E-value、p-value、q-value、跨组差异 | 是 |
| motif 间距/排列统计 | RQ2、必做实验 2/3 | 是 |

不以启动子分类器、启动子强度预测器或生成模型作为本项目主模型；相关任务属于项目池中的其他项目。

## 6. 实验验收矩阵

### 6.1 课程必做实验

| 实验 | 对应问题 | 需要回答的问题 | 主要证据 |
| --- | --- | --- | --- |
| Motif 与已知元件对比 | RQ1 | 发现 motif 与 \`-10/-35 box\`/UP element 的重合度？是否存在新 motif？ | motif 相似性、位置重合、FIMO 命中统计、显著性 |
| 类型间模式差异 | RQ2 | 不同 sigma 类型的 motif 组成和间距是否不同？ | 分组 motif、位置和间距分布、差异检验 |
| 消融实验 | RQ1-RQ3 | 全序列→分组→间距→跨物种验证分别新增了什么信息？ | 逐阶段结果表、图和结论 |
| 跨数据集一致性 | RQ3 | 哪些 motif 跨数据集稳定，哪些只在单一数据集出现？ | motif 相似性、出现率差异、排序稳定性 |

### 6.2 纳入必做的高完成度扩展

课程允许从选做实验中至多选择 2 项。结合项目目标，本组将以下两项纳入必做扩展：

1. **Motif 强度与启动子强度关联**：若数据源包含可比的启动子强度标签，检验 motif 出现/缺失、命中分数和位置与启动子强度的关系；若标签不足，则只做可用数据子集并明确局限性。
2. **Motif 组合模式**：统计多个 motif 的共现关系，构建 motif 组合网络，检验组合是否具有 sigma 类型特异性。

“与转录因子结合位点对比”作为备选扩展：只有在数据质量、映射关系和时间允许时加入，不影响主线交付。

### 6.3 探索项

探索项为调控语法建模：把 motif 和间距模式形式化为规则，用规则检验新启动子的约束满足度。它不是当前阶段的硬性承诺，必须在 M4 主线稳定后再决定。
