# PR01-02 项目约束与任务定义

## 1. 文档角色与信息边界

本文件区分两类信息：

1. **课程附件中的硬约束**：来自 `project-pool.pdf` 的 PR01-02 节，以及 `intro-mlproj.pdf` 中适用于所有项目的课程要求。它们是项目验收依据。
2. **小组项目执行约定**：在不改变课程硬约束的前提下，对数据范围、实验优先级、记录方式和交付标准做出的具体安排。它们会随着数据审计和实验结果更新。

PR01-02 原文没有要求使用 DNA 大模型。课程项目池相邻题目 PR01-01 提到了 DNABERT-2、Nucleotide Transformer 等 DNA 预训练模型嵌入；本组借鉴这一方法，把大模型嵌入确定为主要技术路线。传统方法控制在一套紧凑的课程 motif/间距线，不扩展成与大模型同等规模的第二主线。这个方法调整属于小组方案，不冒充 PR01-02 的教师硬性要求。

## 2. 项目主题和动机（课程要求）

启动子的 `-10/-35 box` 是核心调控元件。不同物种、不同 sigma 因子类型的启动子在核心元件之外，还可能包含 UP element、抑制子结合位点、激活子结合位点等辅助元件。这些元件的组成、位置和排列共同影响启动子的调控特异性与强度。

本项目从多物种启动子序列中系统发现：

- 核心 motif 的变异谱；
- 辅助 motif 的出现频率；
- motif/元件之间的间距分布和排列模式；
- 不同物种、sigma 因子类型和数据集之间的共性与差异。

项目的核心挑战是判断发现的模式是否具有统计显著性，以及是否能在跨物种、跨数据集验证中保持一致。

## 3. 研究问题（RQ）

### 3.1 老师原始研究问题（课程硬约束）

- **RQ1：** 从多物种启动子中发现的 de novo motif，与已知 `-10/-35 box`、UP element 和其他调控元件的重合度如何？
- **RQ2：** 不同 σ 因子类型的启动子在 motif 组成和间距分布上有什么差异，是否存在类型特异模式？
- **RQ3：** 发现的调控模式在跨物种、跨数据集上是否一致，哪些是通用模式，哪些是物种或数据集特异模式？

### 3.2 小组计算化问题（方法实现）

- **RQ1a：** DNA 大模型 embedding 的聚类、近邻和分组结构能否帮助观察不同 σ 因子之间的差异？
- **RQ2a：** 大模型局部遮挡得到的重要区域，是否与 motif 发现结果和已知元件位置重合？
- **RQ3a：** motif、embedding 结构和重要局部区域能否在独立物种或数据集上复现？

最终报告必须先回答老师原始 RQ1–RQ3，再用 RQ1a–RQ3a 说明大模型路线提供了什么额外信息。大模型是本组主线表示方法，但不能替代老师要求的全序列/分组 motif 发现、间距分析和跨数据集验证。

## 4. 总目标和阶段任务

### 4.1 总目标

以 DNA 预训练大模型嵌入为核心表示，从多物种启动子序列中发现聚类、近邻和局部调控模式，分析不同 σ 因子、物种和数据集之间的共性与差异；再用少量传统 motif 扫描解释大模型发现。

### 4.2 老师原文规定的阶段任务

1. **问题定义与数据构建（M1）**：采集多物种启动子序列，按 sigma 因子类型分组。
2. **探索性数据分析（M2）**：分析 `-10/-35 box` 位置分布、GC 含量和类型间差异。
3. **Motif 发现（M3）**：用 MEME/DREME 对全序列和 sigma 分组发现 motif。
4. **间距和排列分析（M4）**：统计 motif 间距离和排列顺序，并按类型比较。
5. **跨物种和数据集验证（M4）**：在不同物种/数据集上重复 motif 发现并计算一致性。
6. **总结（M5）**：回答老师原始 RQ1–RQ3。

### 4.3 小组方法路线与课程任务的对应

- M1/M2 仍按老师要求完成数据构建、sigma 分组、GC/长度/已知元件位置分析；
- 在 M3 中，冻结 DNA 大模型 embedding 作为主要表示分析，同时至少完成一套全序列和 sigma 分组的 MEME/DREME motif 发现；
- 在 M4 中，使用 FIMO 定位 motif，完成 motif 间距/排列统计和跨物种/跨数据集复现；大模型的聚类、近邻和遮挡结果作为主线补充证据；
- 传统工具只保留一套紧凑实验和固定参数，不做多套算法或参数网格，但不能因“传统方法少”而删掉课程必做输出。

## 5. 方法范围

课程建议方法及其在本项目中的用途如下：

| 方法 | 项目用途 | 是否主线 |
| --- | --- | --- |
| DNA 预训练模型 embedding | 序列级表示、聚类、近邻检索和跨来源验证 | 是，项目主线 |
| token/window 表示与遮挡分析 | 定位驱动嵌入差异的局部序列区域 | 是，项目主线 |
| 轻量探针或对比学习 | 诊断 embedding 是否包含 σ 因子相关信息；资源允许时再微调 | 是，分阶段开展 |
| PWM/共识序列 | 对已知 `-10/-35 box` 做最小可解释扫描 | 小型基线 |
| MEME/DREME + FIMO | 对全序列和 sigma 分组完成一套紧凑 motif 发现、定位与已知元件对照 | 课程 M3/M4 最小必做线 |
| 统计检验与多重校正 | E-value、p-value、q-value、跨组差异 | 是 |
| motif 间距/排列统计 | 根据 FIMO 命中位置统计类型差异和跨数据集一致性 | 课程 M4 必做 |

不以启动子分类器、启动子强度预测器或生成模型作为本项目主模型；相关任务属于项目池中的其他项目。

## 6. 实验验收矩阵

### 6.1 课程必做实验

| 实验 | 对应问题 | 需要回答的问题 | 主要证据 |
| --- | --- | --- | --- |
| Motif 与已知元件对比 | RQ1 | de novo motif 与 `-10/-35 box`/UP element 的重合度如何？ | 全序列/分组 motif、FIMO 位置、B0/PWM 对照；embedding 局部区域作为补充 |
| 类型间模式差异 | RQ2 | 不同 sigma 类型的 motif 组成和间距是否不同？ | 分组 motif、间距/排列统计；embedding 分组诊断作为补充 |
| 消融实验 | RQ1-RQ3 | 全序列 motif→分组 motif→间距分析→跨物种验证各增加什么信息？ | 逐阶段结果表；并记录 embedding-only 对照 |
| 跨数据集一致性 | RQ3 | 哪些 motif 和 embedding/局部结构跨数据集稳定？ | motif 一致性、FIMO 位置、kNN/聚类复现和失败案例 |

### 6.2 小组确定的主线实现

在同一批清洗、对齐并完成防泄漏划分的启动子序列上，使用 DNABERT-2 或 Nucleotide Transformer 提取表示。主要结果来自 embedding-only：聚类、近邻检索、跨来源一致性和局部区域解释。传统特征只作为一个小型对照，比较 `embedding-only`、`传统基线` 和 `embedding + 传统特征`，不让传统算法占据主结果篇幅。

以下课程选做方向保留为后续候选，不再同时承诺为两周主线必做项：

1. **Motif 强度与启动子强度关联**：若数据源包含可比的启动子强度标签，检验 motif 出现/缺失、命中分数和位置与启动子强度的关系；若标签不足，则只做可用数据子集并明确局限性。
2. **Motif 组合模式**：统计多个 motif 的共现关系，构建 motif 组合网络，检验组合是否具有 sigma 类型特异性。

“与转录因子结合位点对比”也作为备选扩展：只有在数据质量、映射关系和时间允许时加入，不影响主线交付。

### 6.3 探索项

探索项为调控语法建模：把 motif 和间距模式形式化为规则，用规则检验新启动子的约束满足度。它不是当前阶段的硬性承诺，必须在 M4 主线稳定后再决定。

以下要求来自课程介绍，适用于本项目：

- 保持活跃、合理、清晰的提交记录，避免使用 `update`、`fix` 等无法说明目的的提交信息；
- 建立在线协作文档，记录团队分工、会议纪要和进度追踪；

- 关键实验应能通过命令行复现；

- 最终报告、代码仓库和答辩材料应明确展示问题分析、实验过程、结果、分析结论、协作过程和可复现方法；
