# M1/M2 只读分析：缺口、执行安排与验收表（2026-10-08）

**本清单用于本地 agent 在 M1/M2 正式阶段报告定稿前补证据。** 不重建数据、不重分 train/development/holdout、不重算主标签、不运行 MEME/STREME/DREME/FIMO，不做不同 motif 发现方法比较。正在进行的 M3 STREME 不受此任务影响，两者输出分开。

## 现有不足

- 甲的数据字典/排除清单足够给 M1 一份实质报告；乙的多数 M2 统计已覆盖 GC 与 RegulonDB core 的已知模板简单匹配，丙报告可提取叙述。
- **缺口 A：TJU 六物种的位置描述**。81bp 与 TSS index=61 已知，但乙的汇总没有正式给出六物种、同一口径的 −10 `TATAAT`/−35 `TTGACA` 起点频率、期望窗口占比及 co-occurrence/gap 的只读统计。
- **缺口 B：DBTBS 的相应描述**。432 条 core 具有核验的方向与 TSS，但旧报告因为已撤销的任务分工只做了组成层。应计算同样的描述性统计，并列 SigA 与样本充足的其他 σ；DBTBS 与 TJU 序列重叠不允许把两套结果当独立复现。
- **缺口 C：RegulonDB 全 sigma 位置与解释**。旧表仅对 core 的有限组有说明；需要核对多 σ 的分母、单 σ 的严格过滤以及混合不同 σ 识别元件的误用：Sigma54 等类型不应硬套 σ70 的 −35/−10。
- **缺口 D：独立的结果核验**。乙旧统计可能有固定字符串方向、窗口、有效间距过滤、同源簇计数或 Fisher 检验口径问题；必须以冻结 v2 输入复算，不应照搬组员解释。

## 本地 agent 的只读执行任务（按优先级）

1. **确认数据冻结与来源**：只读核验 `data/processed/pr01_02_data_v2/manifest.json` 所列全部相关 FASTA、`sequence_master.tsv`、`sigma_associations.tsv`、`source_record_mapping.tsv` 的 SHA256；核对 9,708 TJU 正类、8,641 天然负类、RegulonDB core 1,793/extended 2,020、DBTBS 432。若 v2 已被实验脚本改变，停止统计并报告，不覆盖。
2. **写一个统一、只读 M1M2 汇总入口**（建议 `analysis/m1m2_readonly_20261008.py`）。输入只用 v2；输出到一个**新建目录** `results/m1m2_readonly_20261008/`（若目录已存在采用新 run_id，不覆盖）。按来源、物种、标签、core/extended、split 和可用的单 σ 组列明计数、缺失、81bp QC、每条 GC 与合计描述。全量描述可以包含三种 split，但**不可使用 holdout 结果选 motif/修订预注册假设**。
3. **已知元件的纯描述性扫描**：直接检查转录正向字符串 `TATAAT`、`TTGACA`，分别计算严格 exact 和预先规定≤1错配两列；计数单位明确为每条序列至少一次与所有位点次数，两者分列。TSS 位置 `start_1based−61`，只在给定正向主口径下统计，最常见起点、期望区间命中、位置直方图、负样本/生成 shuffle 的对应情况。**不称这个固定共识统计为新的 motif discovery，也不对所有 σ 强称其适用。**
4. **三个来源都做**：TJU 六物种分开展示、RegulonDB 核心并按足够规模的单 σ 组拆分、DBTBS 432 核心并按单 σ 组拆分。RegulonDB extended 单独列描述，不混成核心显著性推断；同源关联跨来源不重复算独立 n。
5. **只读间距**：双命中时先明确一个固定取位规则（如上游 −35 与其后合理方向的 −10 组合，固定优先期望窗口、再选距期望中心最短、并列时左端坐标最小），同时给出无过滤的所有共现及排除的异常/重叠个数。gap = downstream.start−upstream.stop−1；写明坐标基准、是否允许负 gap、计数单位和配对规则。由于不同 σ 元件特性不同，其他 σ 的结果只作模板出现情况，不解释为其真实启动子核心盒。
6. **输出验收**：`input_sha256.json`、`m1_source_inventory.tsv`、`m1_sigma_coverage.tsv`、`m2_gc_length.tsv`、`m2_known_element_hits.tsv`、`m2_tss_position.tsv`、`m2_pair_spacing.tsv`、必要的物种/σ 分布图、`audit.json` 和一份简洁中文 `findings.md`。每张图和每个结论必须能回溯到表、过滤规则、样本数量；所有脚本/版本/种子与输出哈希登记。只包含汇总图表，逐条 DNA、个人路径和原始 FASTA 不放进可提交报告。
7. **复核与合并**：交叉检查历史乙/丙表的样本数、GC 分布和 RegulonDB 共识统计；若有矛盾，以独立复算与审计后的 v2 结果为准，保留差异表，不静默改旧值。最后更新 [M1/M2 阶段报告](M1M2_阶段调查与描述性发现_20261008.md) 补齐明确的发现、限制，标注数据全量摸底≠ holdout 正式验证。

**最小完成标准**：三来源均有同一口径的 M1 数量、质量与 σ 可用性表；M2 有六物种及两个辅助来源的 GC、固定 81bp 结论、可比范围内的 −10/−35 位置/间距；至少一份图、多个可审计统计表和明确的负/不确定发现；没有 M3 motif 发现或未运行实验的虚假结论。若某一源缺少所需原始字段，列出具体字段与记录数、降级分析或说明为什么不能完成，不编造。
