# 数据来源初步审计（2026-09-13）

## 这一步做了什么

本次只推进数据来源核验，没有直接下载数据，也没有把网页上看到的条目当成正式实验样本。目标是先回答三个问题：

1. 数据库到底覆盖什么物种和什么类型的启动子信息；
2. 能不能找到固定版本、可追溯的下载入口；
3. 数据的使用和再分发条件是否明确。

## 已确认的信息

### RegulonDB：优先候选，先作为 E. coli 核心数据源

- 官方资料将 RegulonDB 定义为 **E. coli K-12 的人工整理调控数据库**，包含启动子、转录起始位点（TSS）、sigma 因子和证据等级等信息。见[官方项目说明](https://github.com/regulondbunam/regulondb-docs/blob/main/00_about_policies/about_us.md)。
- 目前可以锁定一个可引用的版本候选：**RegulonDB v12.0.0**，官方 Zenodo 记录发布日期为 2023-09-14，记录号为 [10.5281/zenodo.8346680](https://zenodo.org/records/8346680)。
- 官方 releases 仓库的 [Apache-2.0 LICENSE](https://github.com/regulondbunam/regulondb-releases/blob/master/LICENSE) 可以证明软件仓库的许可，但**不能直接推出数据文件也允许按同样方式再分发**。

## 尚未确认的信息

- 本次审计中 RegulonDB 门户返回了 502，未能从门户完成实时下载验证。
- Zenodo 页面当前能确认记录存在，但没有确认一个可以直接用于本项目的完整 promoter 序列表；因此配置中暂不填写下载 URL、文件名和 SHA256。
- RegulonDB 数据集的再分发条款、具体下载文件格式、序列字段与 TSS/链方向字段的最终对应关系，仍需在下载前确认。

### DBTBS：跨物种候选，暂不立即下载

- 官方页面说明 DBTBS 面向 **Bacillus subtilis**，收录实验验证的基因调控关系、转录因子结合位点和基因上游区域，并列出 sigma 因子等信息。见[数据库说明](https://dbtbs.hgc.jp/ver4/aboutDBTBS.html)。
- 但官方页面存在版本标注不一致：主页显示 **DBTBS release 4.1**，统计页又显示 **DBTBS release 5**，并写明实验数据截至 2007-09-15。见[主页](https://dbtbs.hgc.jp/ver4/home.html)和[统计页](https://dbtbs.hgc.jp/statistics.html)。
- 页面能够作为内容和版本线索，但本次没有确认稳定的批量下载入口，也没有找到清晰的数据再利用/再分发条款。

## 本次决策

当前不下载、不编造版本、不把候选数据库写成“已获得数据”。下一步按下面顺序推进：

1. 先固定 RegulonDB 的实际下载文件和许可说明；
2. 检查文件是否包含 sequence、TSS/坐标、链方向、sigma、evidence 和 source record ID；
3. 保存原始文件、访问日期、版本信息和 SHA256；
4. 只有完成上述记录后，才把它接入清洗和 embedding 实验；
5. DBTBS 作为第二来源，先解决 release 4.1 / release 5 的版本选择，再决定是否用于跨物种验证。

## 对当前项目的影响

这一步没有产生新的生物学结论，也没有改变 DNA 大模型主线。它把正式实验开始前最容易出错的地方先锁定了：**数据来源、版本、字段和许可必须可追溯**。因此当前准确表述仍然是：真实模型 demo 已经跑通，但真实数据实验尚未开始。
