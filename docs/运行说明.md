## STREME 任务入口

每个物种固定使用 `data/processed/pr01_02_data_v2/tjupan_*/main/discovery.positive.fasta`，分两套独立输出：同目录 `discovery.natural_control.fasta`（主）与 `discovery.dinucleotide_null.fasta`（稳健性）；都通过 `--n` 明确输入。示例参数：

```bash
streme --dna --p <species>/discovery.positive.fasta \
  --n <species>/discovery.natural_control.fasta \
  --minw 5 --maxw 15 --nmotifs 10 --thresh 0.05 \
  --seed 20261005 --oc <new_run_dir>/streme_natural

streme --dna --p <species>/discovery.positive.fasta \
  --n <species>/discovery.dinucleotide_null.fasta \
  --minw 5 --maxw 15 --nmotifs 10 --thresh 0.05 \
  --seed 20261005 --oc <new_run_dir>/streme_dinucleotide
```

`<species>` 是每个 TJU v2 `main` 目录占位，`<new_run_dir>` 是全新结果路径。正式执行由本地 agent 根据实际 STREME 版本核验帮助、工具安装、输出开关和路径；固定日志/输入 hash/实际配置。两轮不混合背景、不要直接使用旧 M3/G0 默认路径、不要触碰项目 holdout 作 motif 发现。

M1/M2 的只读补算任务另见 [待补分析](M1M2_待补只读分析与验收_20261008.md)；不要把它当 M3 STREME 数据重建。
