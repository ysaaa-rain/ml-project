configs/m3_tjupan_meme_20261003.yaml

如需续跑，可再次运行相同命令。已经成功且登记在 manifest 的物种会跳过；失败组会按 manifest 和目录状态检查，非空目录不会被覆盖。若进程意外消失且只留下部分输出，先将部分输出目录和日志移动到有日期标记的归档目录，在 manifest 中记录 `interrupted`、已观察到的部分 motif 数和归档位置，再用 `--species <slug>` 单独重跑；运行器会把上次记录追加到该物种的 `attempt_history`，不会静默覆盖尝试历史。需要新建一轮完整实验时，使用新的 run-root 与 result-dir，并同步更改配置和记录。

## 5. 结果质检及后续入口

MEME 退出码为 0 只说明程序正常结束，不代表发现的模式都可靠。每个物种都要检查：

1. 原生 meme.txt 和 meme.xml 是否存在且可解析；
2. primary/control 样本数和总碱基数是否符合输入；
3. motif 数、宽度、E-value、sites 及搜索停止原因；
4. logo/矩阵是否被低复杂度或整体碱基组成主导；
5. 输出哈希与输入 manifest 是否完整。

MEME XML 完整生成后，可从每列概率矩阵绘制统一版序列 logo：

~~~bash
python -m experiments.render_meme_logos --meme-root tmp/meme_runs/tjupan_promloop_20261003 --output-dir results/motif/tjupan_m3_20261003/logos --species bacillus_subtilis baumannii bradyrhizobium diphtheria escherichia_coli staphylococcus
~~~

该图按每列信息量 `2 − Shannon entropy` 缩放碱基字母高度，不做有限样本修正；它是概率矩阵的可视化，不是额外的 motif 检验。脚本同时输出按物种分开的 PNG、六物种 PDF 和记录 XML/图片哈希的 manifest。MEME 原生 EPS 仍保存在本地运行目录，不能把报告 logo 误称为原始 MEME 图。

六组都正常完成后，导出不含序列的 motif 摘要表和 MEME 概率矩阵：

~~~bash
python -m experiments.summarize_tjupan_meme --meme-root tmp/meme_runs/tjupan_promloop_20261003 --run-manifest results/motif/tjupan_m3_20261003/run_manifest.json --output-dir results/motif/tjupan_m3_20261003/summary
~~~

若只为调试指定部分物种，输出 manifest 会标记 `partial_validation_subset`；只有六个物种全部纳入才标记 `complete`。`sites_reported` 是 MEME 位点数，不等于命中的独立启动子数；独立序列覆盖率要等 FIMO 阶段另算。

六组矩阵质检通过后，可对照四个理想化 −10/−35/UP 参考矩阵运行 Tomtom：

~~~bash
mkdir -p tmp/meme_runs/known_element_comparison_20261003/tjupan
for species in bacillus_subtilis baumannii bradyrhizobium diphtheria escherichia_coli staphylococcus; do
  tmp/meme-suite-5.5.9/bin/tomtom -dist ed -min-overlap 6 -thresh 1 -oc "tmp/meme_runs/known_element_comparison_20261003/tjupan/$species" "results/motif/tjupan_m3_20261003/summary/matrices/$species.meme" baselines/known_promoter_elements.meme
done

python -m experiments.summarize_tjupan_tomtom --tomtom-root tmp/meme_runs/known_element_comparison_20261003/tjupan --matrix-summary-dir results/motif/tjupan_m3_20261003/summary --reference baselines/known_promoter_elements.meme --output-dir results/motif/tjupan_m3_20261003/comparison
~~~

Tomtom 只比较 PWM（位置概率矩阵）的形状。当前参考库只有 4 个 motif，软件会警告 p/q 值不可靠；最佳匹配只能作为排序线索，不能据此宣称真实位置重叠或生物学功能。汇总器也会自动断言 σ70 −10/−35 矩阵共识分别为 `TATAAT`、`TTGACA`，避免把名称与实际矩阵再次混淆。

## 6. 六物种首轮 FIMO

六物种自有 motif 的首轮 FIMO 已运行完成；重跑命令：

~~~bash
python -m experiments.run_tjupan_fimo
python -m experiments.summarize_tjupan_fimo
~~~

运行器使用六个物种各自的 10 个 MEME 矩阵，分别扫描正类与有效负类对照合并后的 FASTA。每个物种用自己的 label=0 对照估计 A/C/G/T 零阶背景；FIMO 同时扫描矩阵声明的正链和反向互补链。输入拼接文件、背景文件、FIMO 原生输出和日志均在本地忽略的 `tmp/`。

固定命令选项为 `--qv-thresh --thresh 0.05 --max-stored-scores 1000000`。需准确理解 q 值范围：本机 MEME Suite 5.5.9 的运行日志对每个 motif 分别给出 10,000 个均匀抽样 p 值和相应的 `pi0` 估计；不是把 10 个 motif pooled 后共用一个 q 值。运行 manifest 保存每个 motif 的 `pi0`、输入/背景/matrix 哈希、完整命令、用时和 FIMO 输出哈希。FIMO 的阈值、背景与输出字段见 [FIMO 官方说明](https://meme-suite.org/meme/doc/fimo.html)。

汇总器从 FIMO 原始 TSV 生成去样本 ID 的报告结果：`motif_hit_summary.tsv` 包含每 motif 的 site 数、唯一序列覆盖率以及正负类比较；`position_distribution.tsv` 汇总序列内起点和链。正类/对照差异用唯一序列级双侧 Fisher 精确检验，并对六物种的 60 个 motif/物种项目做 Benjamini–Hochberg 校正；这与 FIMO 输出的单 motif site q 值是两类统计量。

本轮结果边界：MEME 与 FIMO 使用同批正类数据，故不构成独立验证；负类标签是来源文件中的 label=0，不保证是实验确认的非启动子。输入未证实统一转录方向，坐标只作 FASTA 内 1–81 bp 解释。六物种数据和结果的公开许可仍需确认，原始 FIMO TSV 含序列和匹配片段，不纳入普通 Git。

完整数字和解释见[六物种 FIMO 阶段报告](../reports/M4_TJUPan_FIMO阶段报告.md)。

## 11. RegulonDB σ 组留出复核

按 σ 组分别将启动子及其一一匹配的 N1 对照以固定种子划分为约 80% 训练集和 20% 留出集。MEME 只使用训练集发现 motif；FIMO 只扫描留出集，并按配对 N1、跨组命中率和 motif-pair 共现比较。该拆分用于检验同一数据来源内的可重复性，不等同于独立数据集验证。

~~~bash
.venv/bin/python -m experiments.validate_regulondb_sigma_holdout \
  --work-dir tmp/regulondb_sigma_holdout_reproduction \
  --result-dir results/motif/regulondb_sigma_holdout_reproduction
~~~

输入 FASTA、训练/留出拆分、MEME 原生输出和逐位点 FIMO 文件写入仓库内忽略的 `tmp/regulondb_sigma_holdout_20261004/`；汇总表与 manifest 写入 `results/motif/regulondb_sigma_holdout_20261004/`。两个目录都位于项目仓库内。复现实验需确保原始 RegulonDB 输入哈希与本地记录一致。

.venv/bin/python -m experiments.validate_regulondb_sigma_holdout \
  --reuse-meme-runs \
  --work-dir tmp/regulondb_sigma_holdout_20261004 \
  --fimo-work-dir tmp/regulondb_sigma_holdout_fimo_reproduction \
  --result-dir results/motif/regulondb_sigma_holdout_reproduction
~~~
