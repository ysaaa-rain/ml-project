# 运行说明

本文件与代码同步维护。目前仓库已经提供 M1 数据构建和 M2 EDA 的可复现入口；真实外部数据下载、MEME Suite 发现和 FIMO 定位仍需在数据源审计后接入。

## 环境

~~~bash
python -m pip install -r requirements.txt
~~~

MEME Suite 的命令行工具是 motif 发现主线的外部依赖。安装方式、版本和验证命令将在 M1 环境审计后补充；没有安装时不得把本地 Python 处理结果标记为完整实验结果。

## M1/M2 数据构建与 EDA

输入表可以是 CSV 或 TSV，至少包含以下字段：

~~~text
sequence_id  species  source_dataset  sequence
~~~

推荐同时提供 `sigma_factor_type`、`evidence_level` 和 `promoter_strength`。示例输入位于 `tests/fixtures/sample_promoters.tsv`，仅用于代码 smoke test。

运行完整基础流程：

~~~bash
python -m pytest -q
python -m experiments.run_m1 --config configs/m1_demo.yaml
~~~

配置文件中的相对路径以仓库根目录为基准。流程会输出：

- `promoters_clean.tsv`：标准化、质量过滤和精确去重后的 metadata；
- `promoters_clean.fasta`：供后续 MEME/FIMO 使用的序列；
- `background_shuffled.fasta`：保持单条序列长度和碱基组成的随机背景；
- `quality_report.json`：输入/输出数量、缺失/非法字符、分组和长度/GC 摘要；
- `group_summary.tsv`：物种、数据源、σ 因子和发现/验证 split 的统计；
- `position_composition.tsv`：按序列位置汇总的碱基组成；
- `length_gc_distribution.png`、`sigma_factor_counts.png`：M2 基础图形；
- `m1_manifest.json`：本次配置和产物索引。

真实数据运行示例：

~~~bash
python -m preprocessing.build_dataset \
  --input data/raw/promoters_metadata.tsv \
  --output-dir data/processed/m1 \
  --validation-source dbtbs \
  --background-replicates 10 \
  --seed 20260911
python -m experiments.eda \
  --input data/processed/m1/promoters_clean.tsv \
  --output-dir results/m2_eda
~~~

当前默认过滤规则：序列统一为大写 DNA 字母，`U` 转为 `T`；含非法字符、空序列、缺少 ID/物种/数据源、或 `N` 比例超过 `max_n_fraction` 的记录不进入清洗表；重复 ID 和完全重复序列只保留第一条。被过滤和去重的数量必须结合 `quality_report.json` 解释。

## 后续命令约定

所有关键实验使用独立配置文件并支持命令行运行，命令格式统一记录为：

~~~bash
python -m experiments.<experiment_module> --config <config_path>
~~~

运行后必须输出配置快照、输入文件哈希、随机种子、软件版本、日志和结果文件路径。
