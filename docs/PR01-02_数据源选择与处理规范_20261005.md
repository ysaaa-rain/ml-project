更新：2026-10-05。当前数据版本：`data/processed/pr01_02_data_v2/`。

TJU 六物种为主数据；RegulonDB 提供 E. coli σ 标签和可隔离的外部来源验证；DBTBS 提供 B. subtilis σ/TSS/文献注释，不再承担正式独立外部验证。

本研究采用 PromLoop 发布的标准化 promoter 序列，并按其数据集定义视为已经完成 TSS 对齐及必要的方向标准化。81 bp 对应相对 TSS 的 [-60,+20]，TSS 为局部第61位；TJU 不重新截取或反向互补。genomic coordinate、逐条 strand 和原始数据库映射不是 TJU 主实验必要输入。

本段描述 2026-10-05 数据修复验收时的历史状态：当时没有运行正式 MEME/STREME/DREME/FIMO。当前正式 STREME 由本地 agent 执行，状态以其最新实验输出为准。旧 RegulonDB 3,807 条处理输入及其实验结果已从项目移除，不能继续引用旧覆盖率、σ显著性或位置结论。

TJU 六物种 positive promoter → 清洗/去重/泄漏隔离 → MEME/STREME → FIMO → motif position/spacing/cross-species。

RegulonDB E. coli → σ关系表/σ-specific motif → 与 TJU E. coli 做去重叠 cross-dataset validation。

DBTBS B. subtilis → 可靠坐标恢复/σ-specific motif → 与 TJU B. subtilis 做去重叠 cross-dataset validation。

同来源holdout与不同来源验证分别报告；共享序列用于注释，不重复计作独立验证。不同发布来源不保证原始研究独立。

## 2. 课程问题 → 必需字段 → 数据要求

课程原文把 RegulonDB / DBTBS / 基因组注释列为建议技术，不是指定必须使用这三个名称的硬性要求；必须交付的是问题和实验所需的证据。

| 课程问题/实验 | 必需字段 | 数据要求与本方案落点 |
| --- | --- | --- |
| RQ1 de novo motif 与已知元件关系 | sequence、promoter 证据、物种/菌株、motif 或位点 ID、参考 PWM 来源/版本/适用 σ；做位置重合另需位点起止/方向/TSS | TJU六物种正启动子发现集 + 可追溯参考库；以发布TSS对齐窗口分析位置，辅助数据库补充σ与已知位点证据 |
| RQ2 σ 类型比较 | species、sigma ID/标准名、σ 关联证据、promoter ID、sequence；多标签关联表；spacing 还需统一方向 | RegulonDB σ 子集为主；DBTBS 可做 SigA 和小组描述，不把不同物种的 sigma 名称直接合并 |
| RQ3 跨物种 | species、strain/taxon 精度、sequence、可比采样/窗口、独立划分、背景构成 | TJU六物种子集作为主比较；RegulonDB/DBTBS分别补充，不混淆物种效应与来源效应 |
| RQ3 跨数据集 | source_collection、source_release、原始研究/数据库、record ID、sequence、split、跨来源重叠/近同源关系 | 至少两个来源的样本隔离子集；同物种不同来源允许，且有助于固定物种差异；不同文件或同集合拆分不够 |
| motif position | 局部TSS index、发布标准化定义；基因组重建来源另需accession.version/TSS/strand | TJU按采用的PromLoop定义以i−61换算；RegulonDB/DBTBS另做基因组坐标核验 |
| spacing/arrangement | 每条序列的 motif 起止、方向、统一 orientation、TSS、统计单位 | 同一窗口内间距可以描述；转录先后/上游下游须方向明确；跨组还需相同扫描/背景口径 |
| −10/−35/UP 对比 | element_type、物种/σ 适用性、实验支持位点或经引用的 PWM、坐标/参考方向、证据来源 | “像共识矩阵”与“重叠实验证据位点”分开；不同 σ 不强行采用同一元件模型 |
| Exp5 强度关联 | sequence/ID、数值、测量方法/单位、条件、重复、归一化/聚合规则、测量来源、映射 | 不同实验体系不直接混合；本地 E. coli 数值文件是候选，当前只能限定代理数值关联 |
| Exp6 motif 组合 | promoter 序列、motif 多位点记录、可比背景、方向、σ（如果问类型特异）、独立划分 | TJU主线按发布方向做共现/间距/排列，辅助σ线分别分析 |
| Exp7 已知 TFBS 对比 | TF/TFBS ID、assembly、start/end、strand、evidence、关联 promoter/gene、来源版本 | 当前 PromoterSet.gff3 不是完整 TFBS 表，须另取可映射 TFBS 资产；DBTBS 普通 TF 行可作注释候选 |

- 泄漏：同物种跨来源正类、天然负类、反向互补、偏移/indel全query fitting编辑距离≤8组成关联分组；分组整体分配，种子20261005，目标70/10/20。基因组近邻TSS也同侧。八碱基候选索引不丢弃高频词，避免启发式漏检。
