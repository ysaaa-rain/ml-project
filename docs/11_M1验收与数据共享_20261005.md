## 队友如何直接使用

拉取仓库后打开[data/processed/g0_rebuild_20261004](../data/processed/g0_rebuild_20261004/)及其中README。共享文件含标准表、全部簇成员/排除记录、序列hash、strict ML候选、DBTBS候选、三个窗口的固定train/holdout FASTA与训练背景。

M2主输入为`standard_metadata.tsv`：

```python
import pandas as pd

table = pd.read_csv("data/processed/g0_rebuild_20261004/standard_metadata.tsv", sep="\t")
main = table.loc[table["upstream"].eq(80)]
gold = main.loc[main["gold_representative"].eq(True)]
train = gold.loc[gold["split"].eq("train")]
holdout = gold.loc[gold["split"].eq("holdout")]
```

`main`为3,822全部有效位点，`gold`为1,100代表，`train/holdout`为751/349。描述性EDA标明所用集合；发现策略/背景设计以train为依据，holdout不得调参。不要把三个窗口当独立重复；多sigma展开计数不能与独特代表数混用。

共享`share_manifest.json`保存载荷逐文件SHA256、冻结参数、来源hash及原本机manifest的hash。原本机环境manifest留本地，实际科学输入逐字节发布；共享过程没有改变原数据或重跑实验。源码/摘要和共享数据均从同一冻结快照衔接。
