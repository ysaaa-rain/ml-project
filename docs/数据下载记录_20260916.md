# 真实数据下载与第一轮构建记录（2026-09-16）

## 1. 与老师原要求的对应关系

老师给出的 PR01-02 原文要求使用 **RegulonDB、DBTBS 和各物种基因组注释**，收集多物种启动子序列，并按 sigma 因子分组；后续还要做无监督 motif/模式发现、sigma 类型比较和跨物种/跨数据集验证。原文位置见本地课程文件 [project-pool(1).pdf](project-pool(1).pdf) 第 40–41 页。

本次先落实最核心的真实数据入口：

- RegulonDB：作为 *Escherichia coli* 核心来源，提供启动子 GFF3 和对应 K-12 基因组 FASTA；
- DBTBS：作为 *Bacillus subtilis* 的独立跨物种来源，抓取官方 release 4.1 的 promoter 页面，并保留 sigma 因子字段；
- 各物种基因组注释：本轮已保留 RegulonDB 的 K-12 FASTA 作为基因组参考；DBTBS 页面没有可直接对应的统一 TSS/链方向字段，不能凭空补齐。

这一步完成的是“真实来源下载、字段整理和质量控制”，不是最终 motif 结论，也还没有在这批数据上运行大模型 embedding。

DBTBS 页面给出了 promoter 的原始位置字段，但本轮没有证据把它统一解释为项目所需的 TSS 坐标，也没有可靠的链方向字段。因此 `tss_position` 和 `strand` 均保持缺失，第一轮只能使用来源原生上游窗口，不能宣称已经完成统一 TSS 窗口对齐。

## 4. 合并与第一轮真实数据清洗

两个来源分别适配后，用统一合并器拼接：

- 合并输入：4,740 条；
- *E. coli* / RegulonDB：4,042 条；
- *B. subtilis* / DBTBS：698 条；
- 合并表：`data/interim/promoters_metadata_20260916.tsv`；
- 合并表 SHA256：`D30CB844F8A6422E5CD011DED03B275C736C6630EB9049B6398DCADB5120BA15`。

用 `configs/m1_real_native_20260916.yaml` 完成第一轮真实数据构建：

- 输入 4,740 条，保留 4,489 条；
- 删除空序列 92 条；
- 删除重复序列 159 条；
- 非法字符和高 N 含量过滤均为 0；
- 清洗后物种数为 2，来源数为 2；
- discovery 为 RegulonDB 的 3,813 条，validation 为 DBTBS 的 676 条；
- 近同源聚类后 4,481 个簇，跨 discovery/validation 的簇数为 0，当前报告中的泄漏违规数为 0；
- 清洗后序列长度范围 38–93 bp，中位数 81 bp。

输出目录为 `data/processed/m1_real_native_20260916/`，包括清洗表、FASTA、N0/N1 背景、质量报告、分组统计、EDA 图和 manifest。原始数据与生成数据均在 `.gitignore` 中，不把大文件直接提交到 Git；来源 URL、访问日期、文件哈希和构建结果已写入本记录与 `configs/data_sources.example.yaml`。

## 5. 可复现命令

下载和构建入口已经纳入仓库：

```bash
python -m preprocessing.download_regulondb
python -m preprocessing.download_dbtbs
python -m preprocessing.source_adapters --input data/raw/regulondb_promoters_20260916.gff3 --output data/interim/regulondb_metadata_20260916.tsv --source-id regulondb --default-species 'Escherichia coli'
python -m preprocessing.assemble_metadata --input data/interim/regulondb_metadata_20260916.tsv --input data/interim/dbtbs_metadata_20260916.tsv --output data/interim/promoters_metadata_20260916.tsv --report data/interim/assembly_report_20260916.json
python -m experiments.run_m1 --config configs/m1_real_native_20260916.yaml
```
