# 跨来源数据坐标与可比性复核

更新日期：2026-10-03
用途：记录使用来源间序列/位置比较时必须满足的证据门槛。

## 数据来源角色

- TJU Pan 云盘六物种是当前主数据。每条序列 81 bp 的窗口主张来自上游说明；云盘 CSV 没有 strand 与逐条 TSS 字段，转录方向仍需独立复核。
- RegulonDB E. coli K-12 是 σ 分组和跨数据集比较的辅助来源。已构建的 3,807 条序列为 81 bp、按已知链方向对齐到转录方向，并有六类 σ 标签。
- DBTBS release 4.1 B. subtilis 当前为可选来源；既有清洗记录中的 676 条序列缺少可确认的 tss_position 和 strand。

## 坐标与解释判定

| 比较或分析 | 现有证据 | 当前判定 |
| --- | --- | --- |
| TJU Pan 六物种 motif 发现 | 正类长度、碱基和来源文件已核验 | 可以发现 motif；以序列内位置为初始坐标 |
| TJU Pan FIMO 命中解释 | CSV 无方向字段；上游窗口声明不能单独证明逐记录朝向 | 先报告序列坐标；通过独立方向审计后才报告 TSS 相对坐标 |
| RegulonDB σ 组 | 六类 σ 标签和 TSS 方向处理有历史构建记录 | 可用于 σ 分组分析，按实际子集和证据等级报告 |
| TJU Pan / RegulonDB 跨数据集 | 两来源 E. coli 序列存在重叠风险；尚未完成当前版 exact/RC/high-identity 去重 | 只能称验证候选；过滤并核对后才能报告独立复核 |
| TJU Pan / DBTBS 位置比较 | DBTBS 坐标方向字段不可确认 | 不做统一 TSS 位置比较；作为可选序列级 motif 比较需另行审计 |

## 已完成的 RegulonDB 基线证据

RegulonDB 的 −10/−35 共识扫描采用二核苷酸打乱背景。2026-09-28 修复背景生成后，真实集合有 557 个共识命中，N1 背景 554/3,807 条命中，背景命中率 14.552%，高于预设 5%。因此这批位置数字仅用于探索性描述，不能当成显著性结果，也不能替代 MEME/FIMO。

RegulonDB 的 M1/M2 汇总和全体/六 σ 组 MEME 分析保留为辅助实验。详细来源字段及运行参数见 reports/M1阶段报告.md、reports/M2阶段报告.md、reports/M3阶段报告.md 和 docs/MEME环境与Smoke测试_20260930.md。

## 跨数据集比较前的必做过滤

1. 对双方序列统一大小写和字母表，但保留原始序列和来源 ID 的本地映射。
2. 比较完全相同序列和反向互补序列，分别报告过滤数量。
3. 再按固定高相似阈值和算法聚类/过滤近同源序列；预先锁定阈值，不看结果再改。
4. 报告过滤前后序列数、唯一序列数、物种/标签分布和输入哈希。
5. 只有过滤后确实为不重叠样本时，才把来源比较解释为跨数据集复核；否则限定为数据集间描述性对照。

## 许可与发布

数据的下载可用性和代码许可均不能替代数据再分发许可。原始数据及可还原序列的文件保持在本地；发布报告级统计结果前单独确认云盘/来源许可。
