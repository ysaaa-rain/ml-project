## 3. Gate A 决策

**统一 TSS 坐标的正式跨来源实验：未通过。** DBTBS 的 TSS 和链方向缺失，不能把来源原生窗口改写成统一 TSS 窗口，也不能把 `promoter_location` 直接当作统一坐标。

**来源原生窗口的 L0 pilot：有条件通过。** 允许用固定 revision 的 Nucleotide Transformer 在两个来源各抽取 32 条真实记录，目的仅限于检查模型加载、CPU 资源、批处理、向量维度、输出追踪和遮挡流程。该 pilot 不用于 motif 位置比较、跨来源生物学结论或最终 RQ1–RQ3 回答。

## 5. TSS 对齐子集与 B0 位置基线

为推进 M2 的已知元件位置分析，使用 RegulonDB 原始适配表单独构建 TSS 对齐子集，配置为 [`m1_regulondb_tss_20260922.yaml`](../configs/m1_regulondb_tss_20260922.yaml)：4,042 条输入中 3,950 条通过 TSS 窗口条件，去重后保留 3,807 条；所有保留序列为 81 bp，窗口为 `[-60,+20]`，负链已反向互补，近同源簇没有跨 split 泄漏。

在该子集上用 N1 二核苷酸保持背景进行 B0 阈值校准和扫描：唯一长度 81 bp 的完美共识阈值为 `10.354950219366033`，背景命中率为 `0.13265`，没有达到预注册的 `0.05` 目标，因此不能把这次阈值称为满足目标 FPR 的校准。扫描保留 557 个精确共识命中：`-10` 为 367 hits/318 sequences，`-35` 为 190 hits/185 sequences。按 TSS 对齐后的正向扫描命中，`-35` 和 `-10` 的相对起点中位数分别为 `-33` 和 `-13` bp；由于背景 FPR 未达标、B0 的 `p_value_proxy` 不是 FIMO p-value/q-value，这只能作为初步位置描述，不能作为显著性或新调控模式结论。

产物位于 `results/baseline_b0_regulondb_tss_20260922/`，包括校准记录、阈值表、扫描命中表、`position_summary.tsv/json` 和位置分布图；位置汇总由 `experiments/summarize_b0_positions.py` 生成。全量来源原生窗口的 B0 结果另位于 `results/baseline_b0_real_native_20260922/`，其中 DBTBS 位置不作统一 TSS 解释。
