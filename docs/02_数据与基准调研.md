# 数据与基准调研（M1）

## 1. 数据目标

构建一个可追溯的多物种启动子序列库，每条序列至少关联：

~~~text
sequence_id
species
taxon_id
assembly_accession
source_dataset
sequence
sequence_length
tss_position_or_coordinate
sigma_factor_type
known_element_annotations
promoter_strength（若可用）
evidence_level
source_record_id
~~~

实际字段以数据审计结果为准；没有证据的字段不得伪造，使用 unknown 或缺失标记并记录原因。

## 2. 开放数据源候选

| 数据源 | 可提供内容 | 计划用途 | 风险/待核验 |
| --- | --- | --- | --- |
| [RegulonDB](https://regulondb.ccg.unam.mx/) | E. coli 调控网络、promoter、sigma 类型、TFBS 等整理信息 | 高质量已知元件对照、核心数据集 | 物种覆盖集中；下载格式和当前版本需审计 |
| [DBTBS](https://dbtbs.hgc.jp/ver4/home.html) | B. subtilis 调控关系、sigma 因子、promoter 和上游序列信息 | 第二个模式清晰的细菌数据集 | 数据库版本较老，需保留版本和访问日期 |
| [NCBI Datasets](https://www.ncbi.nlm.nih.gov/datasets/docs/v2/reference-docs/command-line/datasets/download/genome/) | 基因组、GFF3 注释、RNA/蛋白和元数据 | 按 TSS/基因注释抽取各物种启动子 | 基因注释不等于实验 TSS，坐标和链方向需严格处理 |
| [CollecTF](https://collectf.org/) | 细菌 TF binding site 的实验验证和人工整理数据 | 选做实验 7 的 TFBS 对比、已知位点验证 | 覆盖物种和 TF 不均衡，需区分证据等级 |
| 物种专属基因组注释 | GFF3/GTF、TSS、上游序列 | 扩展物种覆盖，支撑跨物种验证 | 不同来源坐标、版本和 promoter 定义可能不一致 |

优先使用课程明确建议的 RegulonDB、DBTBS 和各物种基因组注释；CollecTF 作为已知 TFBS 的补充验证源。数据下载前先记录来源 URL、版本/发布日期、访问日期、文件名、SHA256 和许可/使用条件。

## 3. 数据构建规则（待数据审计后固化）

1. 统一 DNA 字母为大写 A/C/G/T/N；含过多未知碱基的序列进入质量过滤日志，不静默删除。
2. 明确启动子窗口相对于 TSS 的坐标方向，并对负链基因做反向互补，使所有序列采用同一相对方向。
3. 区分实验 TSS、注释推断 TSS、翻译起始位点上游近似区间，不能混成同一 evidence level。
4. 以物种、sigma 类型和数据集为主要分组；小样本组不直接参与显著性结论，只作为描述性结果或合并策略敏感性分析。
5. 对重复序列和近同源序列做去重或聚类，防止同源泄漏造成跨数据集一致性虚高。
6. 保留原始记录 ID 和坐标，标准化后的 FASTA 只作为派生文件。
7. 生成机器可读的 metadata.tsv、数据字典、质量报告和文件哈希清单。

## 4. 数据分层和验证设计

数据至少划分为：

- **发现集**：用于 MEME/DREME/STREME 发现 motif；
- **验证集**：用于 FIMO 定位、重合度和跨来源复核；
- **背景/负对照集**：用于评估碱基组成和长度偏差带来的假阳性。

首选按物种或数据集做隔离；如果某一数据源只能提供单物种数据，则使用独立数据源、时间切分或同源聚类后的簇隔离，并在报告中说明限制。

## 5. 基准工具和评测口径

- MEME Suite 的 [FIMO 文档](https://meme-suite.org/meme/doc/fimo.html?man_type=cmd)用于确定 motif 命中、p-value/q-value 和双链扫描的记录口径。
- MEME Suite 的 [STREME 教程](https://meme-suite.org/meme/doc/streme-tutorial.html)说明了短 motif 富集、控制集和样本量选择；少于约 50 条序列时优先评估 MEME，较大样本再加入 STREME 对照。
- MEME Suite 的 [SpaMo 文档](https://meme-suite.org/meme/doc/spamo.html)提供 motif 间距显著性分析的参考定义；本项目将根据启动子相对 TSS 坐标实现更适合多 motif 的自定义间距统计。
- MEME Suite 的 [SEA 输出说明](https://meme-suite.org/meme/doc/sea-output-format.html)用于统一 E-value、q-value 和多重校正的解释。

本项目最终报告同时给出：已知元件恢复、统计显著性、位置/间距、分组差异、跨来源一致性、随机稳定性、组合模式和强度关联，不把单一 E-value 当作项目总成绩。
