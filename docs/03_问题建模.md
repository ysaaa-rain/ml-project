# PR01-02 问题建模

版本：M1.2
日期：2026-09-16

## 1. 建模结论

本项目建模为一个**以 DNA 预训练大模型嵌入为核心、带分组与独立验证的无监督序列模式发现问题**。主任务不是预测“是否为启动子”，而是从已对齐到转录起始位点（TSS）的启动子序列中学习整体和局部表示，发现聚类、近邻与重要片段，并检验这些结构在不同 σ 因子、物种和数据源之间是否复现。

项目输出不是单个分类标签或一个总分，而是由以下对象构成的证据集合：

1. 每条启动子的 sequence embedding；
2. embedding 聚类、近邻关系和跨组差异；
3. token/window 表示及遮挡后变化，用于定位重要局部区域；
4. 嵌入结构在独立数据集中的复现情况；
5. 一套紧凑的 PWM + MEME/DREME/STREME + FIMO 结果，用于完成课程 motif/间距任务并与大模型区域交叉解释；
6. 负对照、重采样和消融实验下的稳定性。

## 2. 输入、输出与符号

### 2.1 输入数据

将标准化数据集记为：

$$
\mathcal{D}=\{(x_i,s_i,g_i,d_i,t_i,e_i,y_i)\}_{i=1}^{N}
$$

其中：

| 符号 | 含义 |
| --- | --- |
| $x_i$ | 第 $i$ 条启动子 DNA 序列，$x_i\in\{A,C,G,T,N\}^{L_i}$ |
| $s_i$ | 物种标签 |
| $g_i$ | σ 因子类型 |
| $d_i$ | 数据源 |
| $t_i$ | TSS 坐标及序列窗口信息 |
| $e_i$ | 证据等级，如实验验证、注释推断 |
| $y_i$ | 启动子强度；仅在来源内可比较时使用 |

所有序列必须统一方向，使上游到下游的相对坐标含义一致。启动子窗口记为 $[-u,+v]$；$u$ 和 $v$ 在真实数据审计后锁定，在锁定前不把某个窗口长度写成正式结论。

### 2.2 大模型表示与传统解释特征

使用 DNA 预训练模型 $f_\theta$ 将序列映射为向量：

$$
z_i=f_\theta(x_i)\in\mathbb{R}^{d}
$$

$z_i$ 是项目主要分析对象。第一轮冻结 $\theta$，记录模型 ID、revision、tokenizer、池化方式和输入截断规则。局部解释保留 token embedding 或固定窗口 embedding，并通过遮挡片段前后的向量变化评估该区域的重要性。

传统 motif 表示只作为解释基线。第 $k$ 个 motif 记为 $m_k$，宽度为 $w_k$，用位置权重矩阵表示：

$$
P_k\in[0,1]^{w_k\times4},\qquad \sum_{b\in\{A,C,G,T\}}P_k(j,b)=1
$$

给定背景碱基分布 $B(b)$，窗口 $z$ 对 motif $m_k$ 的对数似然比得分为：

$$
S(z,m_k)=\sum_{j=1}^{w_k}\log_2\frac{P_k(j,z_j)}{B(z_j)}
$$

仓库当前 `models/pwm.py` 已实现这一可解释得分，用作 B0 已知元件基线。MEME/DREME/STREME + FIMO 只运行一套固定、紧凑的全序列/分组实验，不作为第二条大模型规模的算法主线。

### 2.3 局部区域与传统 motif 命中

motif $m_k$ 在序列 $x_i$ 上的一次命中记为：

$$
h_{ik}=(p_{ik}^{start},p_{ik}^{end},r_{ik},S_{ik},q_{ik})
$$

其中 $r_{ik}$ 为链方向，$S_{ik}$ 为匹配分数，$q_{ik}$ 为多重校正后的显著性。两个 motif 的有向间距定义为：

$$
\Delta_{i,k,l}=p_{il}^{start}-p_{ik}^{end}
$$

$\Delta>0$ 表示 $m_l$ 位于 $m_k$ 下游，$\Delta<0$ 表示重叠或顺序相反。最终同时报告有向间距、绝对间距和排列顺序，避免只报告一个均值。

## 3. 课程问题与小组问题的计算化定义

### 3.1 老师原始验收问题

老师原文的核心验收对象仍然是：de novo motif 与已知元件的对比、不同 sigma 类型的 motif 组成和间距差异，以及跨物种/跨数据集的一致性。对应的最小实验链是“全序列 motif 发现 → sigma 分组 motif 发现 → FIMO 定位 → 间距/排列统计 → 跨来源复现”。

DNA 大模型 embedding 是本组选择的主要表示方法，不是老师原文指定的硬性工具。它与上述 motif 链并行推进：用 embedding 聚类、近邻和遮挡补充模式证据，但不能删掉课程要求的 motif、间距和验证输出。

### 3.2 RQ1a：嵌入空间是否形成有意义的启动子结构

对发现集提取冻结 sequence embedding，在固定预处理下进行 PCA/UMAP 展示、聚类和 kNN 检索。核心指标包括 silhouette、聚类重采样稳定性，以及 σ 因子、物种和数据源标签对应的 ARI/NMI、kNN 一致性。

操作性判定：只有结构在多次重采样中稳定，并且不主要由序列长度、GC 含量、N 比例或数据来源解释时，才认为大模型学到了有意义的启动子差异。UMAP 图本身不算结论。

### 3.3 RQ2a：大模型差异能否定位到具体序列区域

对代表性序列保留 token/window embedding，并对滑动窗口做遮挡或替换，计算遮挡前后 sequence embedding 的变化。将稳定的重要窗口汇总成候选局部模式，再与已知 `-10/-35 box` 及课程要求的全序列/分组 motif 发现结果比较。

核心指标包括重要窗口的重采样稳定性、相对 TSS 的位置分布、与已知元件的区间重合率，以及候选模式在独立验证集中的复现率。“未匹配已知元件”只称为候选模式，不直接宣称发现新调控元件。

### 3.4 RQ3a：嵌入和局部模式能否跨来源复现

发现集与验证集按物种、数据源或近同源序列簇隔离。在发现集固定模型 revision、池化、聚类、近邻和局部解释参数后，只在验证集复核，不反复调参。

核心指标包括跨来源 kNN 检索一致性、聚类中心匹配、组间方向一致性、重要窗口位置与序列模式复现率。只有“整体表示结构”和“局部重要区域”至少一项稳定复现，且来源偏差检查通过，才能形成跨数据集结论。

## 4. 模型与对照体系

## 5. 数据划分与泄漏控制

### 5.1 三类集合

- **发现集**：用于模型选择、聚类/近邻设置和局部解释参数选择；
- **验证集**：只用于固定设置后的嵌入结构、局部区域和跨来源复核；
- **背景集**：与真实序列长度和组成可比的非目标或打乱序列。

同一 split 同时供大模型主线和传统小型基线使用。必须先完成近同源序列簇隔离，再做 embedding 提取和评测，不能让相似序列跨越 discovery/validation。

### 5.2 划分优先级

1. 优先按独立数据源隔离；
2. 再按物种隔离，单独回答跨物种泛化；
3. 同一来源内部必须先按相似序列簇划分，不能把近同源序列分到发现和验证两侧；
4. 若只能获得单一来源，则把结论降级为来源内部重采样稳定性，不宣称跨数据集一致。

### 5.3 混杂因素

所有组间比较至少检查序列长度、GC fraction、证据等级、窗口定义和样本量。必要时使用分层抽样、匹配子集或回归模型控制这些因素。

## 7. 预注册阈值与报告原则

- 大模型主结果必须报告模型 revision、池化、输入长度、设备、随机种子和输入哈希；
- 正式 FIMO 命中默认使用 q-value $\le 0.05$，但只用于传统小基线；
- 所有多 motif、多分组检验使用 FDR 校正；
- 每个比较同时报告样本数、效应量、置信区间和校正后显著性；
- 小样本组先做描述性统计，不强行给出类型特异结论；
- 关键结果至少进行重采样稳定性检查；重采样次数在 pilot 后锁定；
- “显著”不等于“重要”，“未匹配已知 motif”不等于“生物学新发现”；
- 任何结果必须能追溯到输入哈希、配置、软件版本、随机种子、Git 提交和输出文件。

## 8. 消融逻辑

消融不是删掉任意模块，而是逐步回答“每一步增加了什么信息”：

1. **L0 冻结 embedding**：预训练表示是否已经包含可复现结构；
2. **+ L1 聚类与检索**：无监督结构能否对应 σ 因子差异；
3. **+ L2 局部解释**：整体差异能否落到具体序列区域；
4. **+ 独立验证**：嵌入和重要窗口能否跨来源或跨物种复现；
5. **+ 课程 motif/间距线**：全序列与 sigma 分组 motif、FIMO 命中和间距排列能否回答老师的 RQ1/RQ2；B0 和大模型重要窗口用于交叉解释；
6. **+ L3 轻量微调**：只有数据量和独立验证允许时，判断微调是否优于冻结表示。
