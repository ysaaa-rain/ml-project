## 4. RQ 数据安排

- **RQ1**：TJU 六物种主 motif discovery；RegulonDB/DBTBS 提供可靠已知元件和机制注释对照。
- **RQ2**：RegulonDB E. coli sigma 为主；DBTBS 合格 sigma 组补充；TJU 不凭序列推断 sigma 后当真值。
- **RQ3**：分开做跨物种、同来源同源簇 holdout、同物种跨数据集验证。TJU E. coli ↔ RegulonDB、TJU B. subtilis ↔ DBTBS 是标准 cross-dataset validation；先排除 exact/RC/近同源重叠。

## 5. 下一步数据任务

在任何新正式 MEME/FIMO 前，按以下顺序完成：

1. 冻结 TJU 六物种主 positive 入口，明确 `positive_samples.csv` 与 `Dataset.csv label=1` 的逐条关系。

5. 验收 RegulonDB G0 的 sequence/sigma association/split，形成 RQ2 与 cross-dataset 固定输入。
6. 运行 DBTBS 坐标恢复脚本，输出 recoverable/unresolved 清单；验证 `NC_000964` 与当前可用 reference accession version 的兼容性。

8. 生成 final FASTA + metadata + exclusion table + manifest + SHA256。
9. 数据方案验收后才开始正式 motif discovery。
