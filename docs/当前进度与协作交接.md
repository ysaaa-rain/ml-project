## 不能跳过的边界

1. **跨来源统一 TSS 尚未通过 Gate A。** 清洗后的 676 条 DBTBS 记录缺少可确认的 `tss_position` 和 `strand`。`promoter_location` 不能单独当作统一 TSS/链方向证据；不得凭经验补坐标。证据见[Gate A 复核](GateA复核_20260922.md)。
2. **课程 motif/FIMO/间距实验仍未完成。** 当前环境尚未找到可执行的 MEME Suite 工具；B0 不是 MEME/DREME/STREME，也不能代替 FIMO 的显著性与定位结果。
3. **数据再利用/再分发条件仍需单独确认。** 大体积原始数据、模型权重和完整 embedding 不推 GitHub；公开前先检查来源许可，只提交必要的配置、方法、汇总证据和可复现说明。
4. **当前分组诊断是单一来源、单一物种、discovery 集。** 它不回答跨物种、跨来源或独立验证问题，也不能单独回答最终 RQ1–RQ3。

### 向量诊断复现命令

在本地已按数据说明准备好输入、模型缓存与 Python 依赖后，从仓库根目录运行；先确认对应 `results/` 目录可重建，避免覆盖自己要保留的产物：

```bash

  --embedding-dir results/l0_embedding_regulondb_tss_20260924 \
  --output-dir results/l1_structure_regulondb_tss_20260924
```
