## 2. 总体研究链与证据层级

序列与标注审计 → 传统 motif 发现 → 预测定位 → 已知元件恢复 → sigma 特异序列/位置/间距/共现 → 独立验证 → ML 预测消融 → ML 独立 motif 发现。

- RQ1：是否恢复已知核心/辅助元件？PWM 相似、预测位置、已知位点恢复共同评估。
- RQ2：不同 sigma 是否具有不同 motif 组成与空间语法？报告分组差异、效应量及 ML 消融的增量信息。
- RQ3：模式是否跨数据集/物种稳定？只用发现集固定的 PWM、阈值及分析规则验证。
- 评价层次为 pattern similarity、enrichment、predictive information、biological/causal validation。前三层的计算结果不得直接升级为第四层证据。
- embedding、聚类图、attention、归因热图都需要进一步提取实例、聚合对齐、构建 PWM 和验证，才构成 motif discovery。一个 CNN filter 不保证只编码一个 motif。

## 3. 数据角色与纳入标准

### 3.1 角色

- 主要发现数据：E. coli K-12 RegulonDB、B. subtilis DBTBS 中通过 sigma、序列、证据审计的记录。
- 外部验证：其他独立数据集/物种，包括满足要求的课程 TJU Pan/PromLoop 数据。验证用途的数据不得参与该次发现、模型选择或阈值选择。
- 数据库名称不自动赋予 Gold 资格。每条记录须记录证据；DBTBS 的 TSS/strand 缺失不能凭数据库简介补齐。
- 原六物种 TJU Pan 的发现结果保留为旧路线的探索结果；不能把已参与发现的样本重新标为那些旧 PWM 的独立验证集。
- 不因“细菌数据”字样删除数据：本项目本来研究 bacterial promoters。原始 RegulonDB、DBTBS、六物种数据及已选课程扩展的数据属于重要来源。

### 3.2 标准表与去冗余

核心字段：sequence_id、species、strain、sigma_raw、sigma_family、promoter、TSS、strand、evidence、sequence、source、single_sigma/multi_sigma。

补充审计字段：source_version、genome_accession/version、genomic_start/end、source_record_id、coordinate_status、window、sequence_hash、cluster_id、split、exclusion_reason。保留原始标签和可追溯映射。

完全重复、反向互补重复及高度近似序列需审计；聚类前冻结 identity、coverage、比对方式和阈值，不能把不同覆盖条件的“90% identity”当成同一标准。保存成员映射和删除/保留原因。发现/验证及 ML 划分以同源簇隔离；cluster 的构建可用序列但不得用测试标签选阈值。

multi-sigma 可进入对应发现组，但不能同时作为该 sigma 的负对照；严格多分类 ML 主实验仅用 single-sigma。多标签/多 sigma 作为独立扩展，不任意取第一个标签。

### 3.3 方向和坐标

主窗口相对 TSS 为 [-80,+20]；敏感性窗口 [-60,+20]、[-100,+20]。本规范采用 TSS=0、闭区间，因此分别是101/81/121bp。保存实际提取边界，跨基因组边界的处理方法须明确。

序列统一转录方向 5′→3′，负链按可靠链注释 reverse-complement；保存源基因组坐标和转换。不得重复翻转已标准化的序列。

使用无基因组坐标含义的 FASTA ID 时，FIMO start/stop 为序列内1-based inclusive；主窗口 TSS 索引为81，relative center=(start+stop)/2−81。其他窗口使用各自实际 TSS 索引，不硬编码81。FIMO 命中 strand 相对输入序列，与原基因组 strand 分开保存。

现有81bp数据不能靠补N或推断补成101/121bp；须由真实参考基因组、版本、TSS和链重新提取。可靠 TSS/方向缺失的数据只用于序列发现及序列内探索，不进入严格 TSS 位置/间距验证。其不可用项明确写 NA 和原因。

## 4. 七个实验及验收

| 新编号 | 任务和方法 | 核心验收 |
|---|---|---|
| 1 | species×sigma 分组 MEME/STREME | PWM、consensus、width、logo、显著性类型/数值、site count、unique sequence count、信息量、输入数、两套背景 |
| 2 | 固定 PWM 用 FIMO 扫描 | 完整 site 表、唯一启动子命中率、score distribution、可靠坐标下的 position density |
| 3 | Tomtom 与细菌已知 sigma 元件比较 | 库来源及证据、对齐、p/E/q、known recovery、匹配与未匹配结果 |
| 4 | sigma-specific motif grammar | 序列/出现率/位置/间距/顺序/orientation/共现；效应量、BH-FDR、自编统计与 SpaMo 对照 |
| 5 | within-species holdout、cross-dataset、对应 family cross-species | 固定 PWM 验证、命中率/OR/位置与间距一致性、按簇 bootstrap CI |
| 6 | motif 特征预测 sigma | Logistic + RF或XGBoost；A–D消融、分组划分、GC控制、全部指标及解释 |
| 7 | CNN→归因→TF-MoDISco→PWM | 独立 ML 实例及 motif；Tomtom/FIMO/known motif 交叉比较、固定模型的独立验证 |

### 实验1：发现

正式发现组按去冗余后的发现集样本数判断：n<10不作正式统计组；10–49以MEME为主；n≥50以STREME为主。该划分是本项目方法规则，不是软件最低输入限制。主宽度5–15bp；停止规则、最大motif数、种子、背景阶数先冻结。

两套对照：A 保持组成的 shuffled promoters；B 同物种其他sigma promoters，排除携带目标sigma的多标签记录。匹配长度及GC，报告匹配后的差异和样本流失。随机背景的 k-mer 阶数/实现/种子须记录，不混用二核苷酸与三核苷酸保持背景。

MEME 小样本结果需与两套对照作固定 PWM 扫描比较；普通 MEME 不能靠修改 Markov background 文件冒充“显式其他sigma负集的差异发现”。若采用差异目标或额外扫描统计，须记录实际实现。

代表性组作 MEME/STREME/DREME 鲁棒性，不机械地全部运行。保存软件实际给出的 p/E/score，不把不可用 p-value 的 score 强写成 E-value。STREME 自带用于估计显著性的 holdout 不是实验5的独立测试集，且其最终 PWM 会使用内部 holdout；实验5外部测试必须另行隔离。

### 实验2：定位

site 表：sequence_id、motif_id、start、stop、strand、score、p_value、q_value、TSS_relative_center、coordinate_status、scan_id。

严格分析 q≤0.05；候选 p<1e-4 单列用于敏感性分析。扫描时必须保留足以计算并筛选严格 q 的结果，不能仅导出已截断的 p<1e-4 表再自行当完整检验族校正。记录 FIMO 版本、背景、双链选项、扫描范围、q计算方式/检验族和储存上限警告；无q输出不得算严格通过。

区分 site q、Tomtom q、启动子富集检验q、跨motif/跨group多重比较q。候选raw p与严格site q的命中率分别报告。扫描到零严格位点也必须完整留证。坐标写 predicted occurrence，不写实验验证结合位置。

### 实验3：已知元件恢复

主库来自 RegulonDB、DBTBS、实验文献的 bacterial sigma 元件，兼顾 UP/辅助调控元件；JASPAR不能作为唯一标准。实验位点对齐生成 PWM 时保存位点来源、样本数、对齐和伪计数；同一实例与发现/测试重复的情况登记。

从 consensus 合成的理想化矩阵与真实实验位点 PWM 分开标记；旧四模板只作探索参照。Tomtom报告所有候选及p/E/q、对齐与注释；PWM similarity 不自动等于位置重合或真实功能恢复。数据库未匹配不能据此否定新motif。

### 实验4：语法

先建立可追溯 sigma-family mapping。σ70-family按−35/−10等架构分析；σ54单列−24/−12，不能凭名称数字跨物种直接配对。

统一主间距定义：按转录方向序列坐标排序，gap = downstream.start − upstream.stop − 1；0为相邻，负数表示重叠。同时保存两个site的坐标、宽度、center_distance、motif顺序及hit strand。center distance与边缘gap不得混在同一列。

预先规定每启动子的pair选择方法、是否纳入重叠及双链组合。启动子/同源簇是独立样本单位，多个命中不能当独立生物重复。连续变量根据设计和分布用ANOVA/Kruskal-Wallis或相应置换；类别用Fisher/Chi-square；报告效应量、CI及明确的BH检验族。

自编 spacing 与 SpaMo 作方法交叉检查。短窗口需依据motif长度设置margin/range并报告丢弃数；同一数据换工具不是独立生物验证。SpaMo主motif内部区域选择与自编pair集合不一致时，先解释可比样本和定义。

### 实验5：验证

建议新划分70/30；按簇隔离、保证可行的sigma覆盖，并在运行前冻结。小样本无法合理划分时登记不足，不强行给出泛化结论。已有80/20结果按原划分保留，不能改称70/30。

独立数据先排除精确、反向互补及高相似重叠。来源不同不保证独立，同数据库内部holdout只称同来源验证。cross-species按生物对应family；记录候选是否已通过发现/模型选择见过验证物种。

验证集只扫描固定 PWM 和预定阈值；测命中、OR、position/spacing一致性和按簇bootstrap CI。验证失败后提出新探索可以，但须新版本、新验证数据，不反复使用原测试集宣称成功。

### 实验6：ML pattern validation

输入presence、max score、hit count、position、pair spacing、co-occurrence及GC控制。无命中特征采用明确mask/NA及训练集拟合的填补方案，不把缺失位置填0当TSS命中。

模型主组合为Multinomial Logistic Regression + Random Forest或XGBoost之一。消融A k-mer；B motif score/presence/count；C B+position；D C+spacing/co-occurrence。统一split、调参预算和GC控制；另报GC-only对照及必要的GC匹配置换。

训练内发现motif、选择特征、标准化/填补和调参；cross-validation每折都重新执行训练折motif发现及特征构建，或使用与各折完全独立的固定来源motif库并明确说明。不能用全数据按sigma发现motif后仅对分类器做CV。测试标签不参与motif筛选、归因头选择或阈值选择。

指标：macro-F1、balanced accuracy、MCC、macro-AUROC、confusion matrix，附类别支持数和簇级CI。缺失类别或AUROC不可计算时写NA及原因。解释采用permutation importance或SHAP；报告position/spacing带来的增量及不确定性。预测改进支持判别信息，不能“证明”生物作用。

### 实验7：ML独立发现

默认one-hot→compact 1D CNN→sigma classifier→IG或DeepSHAP→TF-MoDISco→ML PWM。模型、早停、归因baseline、片段选择/聚类参数只在训练及内部验证确定；ML发现不能使用传统PWM作为训练标签或候选过滤条件。

保存seqlets、序列与碱基贡献、正负贡献方向、聚类/对齐、PWM、模型/参数/seed。适配所选TF-MoDISco实现要求的actual/hypothetical contribution scores及通道坐标；IG热图不能直接冒充所有实现所需输入，接入前核对格式。

提取完成后用Tomtom比较传统及已知PWM，用FIMO检验位置和spacing，在保留集检验模型和motif恢复。模型归因/计算突变只能解释模型行为；不得称湿实验功能确认。

DNABERT-2/NT frozen embedding作为1–2数据集的资源允许扩展；需保留token到碱基映射及明确extraction机制。仅缓存的pooled embedding无法做碱基IG；须可微的原模型输入通路或另一种合理实例定位方式。Attention候选需归因/扰动与独立扫描验证。SAE非必做，重构质量不等于motif质量，蛋白/RNA成功案例不保证细菌DNA迁移有效。

## 8. 方法核对与引用边界（2026-10-04）

以下核对只用于方法解释，不是本项目验证结果；综述全部文献未逐条核验。

- [STREME官方说明](https://meme-suite.org/meme/doc/streme.html)：内部holdout过小时显著性估计受限；最终PWM也利用内部holdout，因此新5测试须另设。
- [FIMO官方说明](https://meme-suite.org/meme/doc/fimo.html)：支持site q阈值；达到stored scores上限可能截断结果并使q近似，manifest需记录。
