## 一、职责与数据源

**TJU / PromLoop 六物种**主序列（v2 9,708 条规范化唯一正类），TSS=61、窗口 [-60,+20] 的 81bp 标准化方向由上游发布定义采信，不按 strand 再 RC。TJU 无逐条可靠 σ 注释，不能凭字符串猜 σ。正式入口仅用 `Dataset.csv` 的正类及经 v2 冻结的 FASTA；`positive_samples.csv` 六物种 9,724 条已与原始 Dataset.csv label=1 全字段一致，只保留 raw 原件，不作为第二入口。

**RegulonDB** E. coli：GFF3 Sequence 已转录定向，禁止负链二次 RC；core 唯一序列 1,793，保留多对多 promoter–σ 标签；可用于 σ 专项及与 TJU E. coli 经过重叠隔离的外部验证（当前 core holdout 250 条候选）。σ 元件解释要区分 promoter confidence 和 σ association evidence。

**DBTBS 4.1** B. subtilis：经过 `Direction + Location + Absolute position + HTML TSS` 与 **NC_000964.2** 核验后核心 432 条，作为 TJU B. subtilis 缺失的 σ/TSS/文献注释与只读描述补充；与 TJU 存在 409 条完全重复和 20 条≤8编辑直接相关，只有 3 条无关联（其中 holdout 仅 1 条）。**取消 DBTBS 正式独立外部统计验证分支；不得把这 1 条包装成验证实验。** 不删除可追溯的 DBTBS 来源。

## 二、课程阶段

**M1 和 M2 是只读数据分析阶段**，不是 RQ1/RQ2 或算法对比。M1 分析三个来源的数据类型、σ 覆盖、来源可靠性/质量；M2 描述长度、GC、已有 −10/−35 共识在 TSS 对齐窗口的位置/间距以及 σ 组差异，并清楚说明统计不足处。现有证据与缺口见 [M1M2 整编报告](M1M2_阶段调查与描述性发现_20261008.md)及[待补任务](M1M2_待补只读分析与验收_20261008.md)。

**M3 以后才执行 de novo motif**；发现使用各物种固定的 v2 discovery，禁止动用项目 holdout 选择 motif/阈值。

## 三、M3 主程序和两套 background（用户最终决定）

每物种相同 `discovery.positive.fasta`，**分别**运行两轮 STREME：
1. **主实验**：`discovery.natural_control.fasta`（原发布 label=0）；
2. **稳健性实验**：`discovery.dinucleotide_null.fasta`（已生成并冻结的二核苷酸保持 shuffle）。

两套 `--n` 不混合、不事后挑结果、不把 shuffle 称天然负样本。正负 GC 差异记录为解释限制；**不新增 GC-matched 背景，不做 GC 分层聚类**。固定相同工具版本、物种对应输入哈希、`--minw 5 --maxw 15 --nmotifs 10 --thresh 0.05 --seed 20261005`，详细以预注册和实际 STREME 版本帮助为准。正式候选从 natural 主实验按预先规则选择；shuffled 对照用于 PWM/富集稳健性检验，不改变主列表。

**MEME** 留待选定代表物种做方法互证；**DREME** 暂不跑；固定 motif 后用 **FIMO** 作位点/位置/间距/共现。FIMO 主严格 `q≤0.05`，raw p<1e−4 仅探索，统计检验另做 BH。参考 PWM 主来源按物种与 σ 筛选 RegulonDB/DBTBS，四个理想共识不冒充实测 PWM；位置与语法检验严格按最新预注册进行。

## 四、冻结数据与验收底线

- 不重建、不覆盖 `data/processed/pr01_02_data_v2`；manifest 的 raw/output SHA256、排除原因、关联组与 frozen split 是唯一现行冻结账本。
- 精确/反向互补重复用于去重；近同源关联规则是 81bp 全查询拟合、两个方向、≤8 编辑操作。关联组整体划分到 discovery/development/holdout；不得把操作性阈值说成“已证明绝无同源关系”。
- M1/M2 的新增分析只读 v2，另存新输出，不能为了得到更好的结论修改预注册、改阈值、删除阴性结果。
- 每次新 STREME/MEME/FIMO 都保存输入 hash、命令、工具版本、样本数、seed、输出 hash、错误与阴性发现；不能引用已经删除的旧 RegulonDB 二次翻链派生结果。
- 研究问题 RQ1/RQ2/RQ3 与老师的必做实验仍须逐项提交；低样本 σ 组必须明确探索/描述性质。跨来源独立、同来源留出、跨物种三种验证分开结论。
