# PR01-02 M1/M2：三数据源调查与描述性发现

**阶段报告整编版（2026-10-08）｜状态：已有证据整理完成，三来源统一位置调查待补算后方可称最终验收。**

说明：M1/M2 是老师要求的**只读数据理解、基本统计和初步发现**，不是 RQ1/RQ2 的别名，也不是 MEME/STREME/FIMO 实验。本报告由 2026-10-07 甲、乙、丙提交的统计与 v2 冻结 manifest 汇整；数字可追溯，但除已独立对照的原始数量外，**没有在 10-08 对所有原始序列重新独立计算全部 M2 统计**。不应把本报告当作新 motif 实验结果。

## 一、M1：研究问题、来源与数据体系

目标是研究多物种细菌启动子中的短序列模式、TSS 相对位置和调控类型差异，兼顾同来源留出及跨来源验证的独立性。

| 来源 | 物种/范围 | v2 记录单元（81bp） | 其中正样本 | 当前角色与特殊限制 |
| --- | --- | ---: | ---: | --- |
| TJU Pan / PromLoop | 六种细菌 | **18,349** | **9,708** | 主要正/负序列、六物种比较；无逐条 σ 与基因组坐标 |
| RegulonDB | E. coli K-12 | **3,813** | **3,813** | 实验注释的 σ 分组与坐标/文献；core 1,793，另有 extended 2,020 |
| DBTBS 4.1 | B. subtilis | **432** | **432** | σ/TSS/方向/位点辅助注释；不能作为有效独立外部验证 |
| **来源内记录合计** | — | **22,594** | **13,953** | **非跨来源独立 DNA 序列总数**；TJU 天然负类 8,641 |

三类数据的统一观察窗口为 81 bp、相对 TSS 的 `[-60,+20]`、序列内 1-based TSS index=61。RegulonDB 已修复负链二次 reverse-complement；DBTBS 使用 **NC_000964.2** 验证可靠坐标；TJU 采用 PromLoop 发布方向与 TSS 对齐，不能声称逐条已独立恢复 genomic strand。

TJU 原始六物种 `Dataset.csv label=1` 合计 9,724 条，六份 `positive_samples.csv` 逐 ID、全字段完全一致，因此后者不作独立数据源。v2 经冲突隔离与规范化/去重后保留 9,708 条正样本。`label=0` 与 `dinucleotide_null` 的用途不同，不能把打乱序列叫天然 non-promoter。

### σ 分组的覆盖情况

TJU **没有可直接据以分组的逐条 σ**。RegulonDB（Sigma70/Sigma38/Sigma32/Sigma24/Sigma54/Sigma28）与 DBTBS（SigA、SigB、SigE 等）有多对多 σ 关联；只有**单 σ core** 可组成互斥分组，不能将来源记录的多个 σ 自动选一个。

乙提供的互斥分组汇总共 19 个 σ 组，其中达到预定 `总量≥50、discovery≥30、holdout≥20` 门槛的仅 RegulonDB **Sigma70：817** 和 DBTBS **SigA：249**；8 组探索性、9 组只描述。门槛仅代表**后续数据量许可**，不是 M1/M2 已经做出了生物学确认。Sigma70 与 SigA 属不同物种，不直接作 σ 作用差异检验。

### 重复与独立性

现有序列比对：DBTBS 的 432 条中，**409** 条与 TJU B. subtilis 正样本完全相同；另 **20** 条与最近的 TJU 正样本编辑距离分别为 1（15条）、2（3条）、3（1条）、6（1条）；只有 **3** 条未触发当前编辑距离≤8的直接相关规则，且只有其中 **1** 条属于 holdout。DBTBS 因而**不承担独立外部验证**，但包含 TJU 不具备的 σ/TSS/文献注释。RegulonDB core 外部留出候选 250 条，仍需按冻结规则进行后续正式验证。当前图隔离判定为 full-query fitting 双方向编辑距离≤8，同一关联组不跨 discovery/development/holdout；阈值是操作性防泄漏规则，不等于生物学完全独立证明。

## 二、M2：已取得的描述性结论

### 1. 长度与序列组成

22,594 条**冻结输入窗口全长均为 81bp**。这个“长度相同”是窗口设计造成的，不是细菌启动子天然长度完全一致的发现。

| TJU 物种 | 启动子 GC 中位数 | 同物种 label=0 GC 中位数 | 差（百分点） |
| --- | ---: | ---: | ---: |
| B. subtilis | 33.333% | 46.914% | −13.580 |
| Baumannii | 33.333% | 40.741% | −7.407 |
| Bradyrhizobium | 60.494% | 65.432% | −4.938 |
| Diphtheria | 46.914% | 55.556% | −8.642 |
| E. coli | 44.444% | 53.086% | −8.642 |
| Staphylococcus | 24.691% | 34.568% | −9.877 |

**发现：** 六物种中正样本 GC 中位数均低于同物种原始负样本；跨物种正样本 GC 中位数差异很大（约 24.7%–60.5%）。这一点是数据组成的观察，不等同于证明特定 motif 的功能。历史乙统计还记录二核苷酸保持打乱背景与对应正样本 GC 相同；正式后续 STREME 已明确采用天然负样本主背景 + shuffle 稳健性背景，无需 GC-matched 分组。

辅助来源 GC 中位数：RegulonDB E. coli 正样本 **41.975%**；DBTBS B. subtilis 核心正样本 **33.333%**。不同来源的抽样、标签/σ 构成不一致，不能把数值差别直接归因于物种或 σ 生物学差异。

### 2. −10/−35 已知共识的只读扫描（已有可靠汇总限 RegulonDB）

乙在 **RegulonDB core discovery 1,284 条**上，以转录正向的教科书共识序列 `TATAAT`（−10）和 `TTGACA`（−35）作固定字符串匹配。这只是**已知模板出现情况**，不是 de novo motif discovery、不是 FIMO 或已验证短位点 PWM。定义的期望起点区间：−10 为 −12..−7，−35 为 −37..−32。

| 元件 | 精确匹配至少一次 | 随机二核苷酸对照 | 精确匹配最常见起点 |
| --- | ---: | ---: | ---: |
| −10 `TATAAT` | **74/1284 (5.76%)** | 67/1284 (5.22%) | −12 |
| −35 `TTGACA` | **42/1284 (3.27%)** | 33/1284 (2.57%) | −36 |

两类共识**精确出现率相对 shuffle 未检测到显著差异**（源表分别 Fisher p=0.6034、0.3485），不能解读成生物元件不存在，因为实际结合位点存在简并。允许≤1次错配时，−10 命中 762/1284（59.35%），−35 命中 551/1284（42.91%）；这一口径更宽、假阳性也更多，只作描述性敏感性观察。

### 3. −10 与 −35 的共同出现及间距

在同一 RegulonDB core discovery：两个共识都被**精确匹配**的只有 **2 条序列**；符合源表间距有效范围的只有 **1 对**，间距 18 bp，**不能据此推断稳健的间距分布**。在允许≤1个错配时，共现 314 条，其中 179 个有效间距配对，中位间距 **17bp**、均值 **18.22bp**，但由于匹配宽松且采用选位/过滤规则，这只是预先指定元件位置的**探索性结果**。Sigma70 单标签发现集按相同宽松规则有效间距 97 对、中位数 17bp；其余 σ 组数据量明显偏少。不能把上述字符串配对当作经过 STREME/FIMO 的正式 motif spacing。

### 4. 按 σ 类型差异的描述

旧统计显示 RegulonDB core discovery 的 Sigma32 GC 中位数比 Sigma70 高约 3.09 个百分点（乙回归汇总 BH q≈0.0064）；DBTBS 的 SigB/SigE/SigG/SigK 相较 SigA 也有中位数差异，但各小组发现样本仅约 18–24 条，属探索观察而不是生物调控特异性证明。源表应报告原始样本量、差与校正范围，避免跨来源比较以及把 σ 标签来源等同于实验确认。参见下方 `T16/T17/T18`。
