# DNA 大模型嵌入主线方案

版本：M1.1
日期：2026-09-13

## 1. 这部分从哪里来

PR01-02 教师原文要求的主线是：从多物种启动子序列中发现 motif，分析位置、间距和组合，并做跨物种、跨数据集验证。原文没有要求 DNA 大模型。

课程项目池相邻题目 PR01-01 提到了 DNABERT-2、Nucleotide Transformer 等 DNA 预训练模型嵌入。本组借鉴这一建议，把“大模型嵌入”确定为 PR01-02 的主要技术路线。这个选择属于小组方案，不能被表述成教师对本题的硬性要求。

## 2. 为什么值得加

MEME/FIMO 擅长回答“哪些短序列反复出现、出现在哪里”；DNA 大模型嵌入把整段序列压缩成向量，更适合观察“整段序列在整体上是否相似”。两条路线看到的信息不同：

- motif 路线可解释，能指出具体碱基模式和位置；
- 嵌入路线可能捕捉更分散、更长程的序列特征；
- 二者结合后，可以检查大模型看到的结构能否被具体 motif 解释，而不是只展示一张降维图。

因此，大模型在本项目中的角色是“主要表示和主要结构分析工具”。PWM、MEME、STREME、FIMO 只选一套紧凑课程线，但仍覆盖老师要求的全序列/分组 motif、FIMO 定位和间距/排列；它既用于课程验收，也用来说明大模型关注的区域是否能与传统元件对应。

## 3. 大模型主线研究问题

**RQ1：** embedding 能否形成稳定的启动子结构，并反映 σ 因子差异？

**RQ2：** token/window embedding 和遮挡分析能否定位重要序列区域，这些区域是否对应已知调控元件？

**RQ3：** embedding 聚类、近邻关系和重要区域能否跨物种、跨数据源复现？

传统 motif 方法不形成与大模型同等规模的第二主线，但作为老师 M3/M4 要求的最小实验线，直接回答 motif、间距和跨数据集一致性问题。

## 4. 模型选择规则

第一轮已经锁定一个模型，不同时铺开多个大模型：

~~~text
model_id: InstaDeepAI/nucleotide-transformer-v2-50m-multi-species
revision: f1ff02bacb08d292ee9c3e227356d692055ac50d
pooling: mean
~~~

模型信息以[官方模型卡](https://huggingface.co/InstaDeepAI/nucleotide-transformer-v2-50m-multi-species)为准。模型卡标注 `CC-BY-NC-SA-4.0`；课程展示前复核许可，模型权重不提交 Git。

选择依据和正式数据运行前的复核项如下：

1. 模型权重和代码是否能稳定获取；
2. 许可证是否允许课程项目使用和展示；
3. 最大输入长度是否覆盖统一启动子窗口；
4. CPU/GPU 内存和预计运行时间是否可接受；
5. tokenizer、模型 revision 和池化方式能否完整记录。

真实权重已在 6 条 demo 上完成 smoke。第一轮保持模型参数冻结，先建立可靠主基线。若真实数据量、标签质量和显存允许，再加入线性探针、对比学习或 LoRA；不做高成本全量微调。DNABERT-2 只保留为不可用时的备选，不并行比较两套大模型。

## 5. 输入和输出

### 输入

- 统一清洗后的启动子序列；
- 统一方向和 TSS 相对窗口；
- 在特征提取前完成 discovery/validation 和近同源序列簇隔离；
- 物种、数据源、σ 因子和证据等级只作为分组或评测元数据，不拼进 DNA 序列文本。

### 输出

- 每条序列一个固定长度的 sequence embedding；
- 可选的逐 token embedding，仅在需要定位局部信号且资源允许时保留；
- 模型 ID、revision、tokenizer、最大长度、截断规则、池化方式、设备、数据类型和批大小；
- 输入文件 SHA256、序列 ID 顺序和输出文件 SHA256。

模型权重和大体积 embedding 默认不提交 Git，只提交配置、摘要指标、小型图表和可重建记录。

## 7. 评测方法

主任务仍是无监督模式发现，但主要证据来自大模型。评测分四层：

1. **无监督结构**：PCA/UMAP 只用于展示；聚类质量报告 silhouette 等内部指标。
2. **带标签诊断**：用 σ 因子、物种或数据源计算 kNN 一致性、ARI/NMI；这些标签只用于解释，不把项目改成分类任务。
3. **局部解释**：报告重要窗口、遮挡前后 embedding 变化、相对 TSS 位置和重采样稳定性。
4. **轻量探针**：可选线性分类器只作为“嵌入含有什么信息”的诊断，报告 macro-F1 和独立验证结果。

最关键的对照是：

| 表示 | 包含内容 | 要回答的问题 |
| --- | --- | --- |
| embedding-only | 冻结大模型向量及局部表示 | 项目主要结果 |
| traditional-small | B0 与一套全序列/分组 MEME/DREME/STREME + FIMO 摘要 | 提供课程要求的最小 motif、定位和间距参照 |
| combined | embedding + 少量传统特征 | 检查传统信息是否带来补充 |

只有 embedding 的聚类、检索或局部模式在独立验证集或跨来源评测中仍稳定，才可以说大模型主线有效。一张好看的 UMAP 图不能单独作为结论，combined 也不要求必须超过 embedding-only。

## 8. 泄漏和偏差控制

- 先按近同源序列簇划分，再提取和评测嵌入；
- discovery 上确定池化、降维和聚类设置，validation 上只复核；
- 检查嵌入是否主要编码序列长度、GC 含量、N 比例或数据源格式；
- 比较长度/GC 匹配子集，必要时对这些变量做残差化或分层分析；
- 不在验证集上微调模型或反复选择最佳参数；
- 对模型不可访问、输入过长、内存不足和运行超时保留失败日志。

## 9. 两周内的主线交付

两周阶段只承诺完成以下最小闭环：

1. 选定并记录一个可运行的冻结模型；
2. 在少量真实序列上完成 L0 smoke test；
3. 对完整可用样本提取 sequence embedding；
4. 完成聚类、近邻检索和至少一种局部解释；
5. 至少做一次按数据源或物种隔离的验证；
6. 运行一套全序列/分组 PWM + MEME/DREME/STREME + FIMO，并根据命中表完成 motif 间距/排列统计；
7. 如大模型运行受阻，记录具体原因并更换可运行的小型号 DNA 预训练模型，而不是把传统算法自动升级为主线。

截至 2026-09-24，仓库已有可运行的嵌入提取、聚类、近邻、PCA、遮挡和追踪代码，并已完成 RegulonDB/DBTBS 真实数据的第一轮来源原生窗口构建。固定 revision 的真实模型已在 64 条 pilot 和全部 4,489 条来源原生窗口上运行，生成 `4489×512` embedding、聚类/近邻和第一版偏差诊断；在 RegulonDB 的 3,807 条 TSS 对齐子集上完成 28 条分组代表序列的 L2 遮挡探索，并对全部 3,807 条序列完成一次分组向量诊断。该诊断中 sigma 与聚类的 ARI/NMI 为 `0.00014/0.00207`，已知 sigma 最近邻一致率为 `41.69%`，接近随机基线 `41.70%`，目前没有 sigma 特异结构证据。模型权重保存在本机 Hugging Face 缓存而不提交 Git。由于 DBTBS 缺少可确认的统一 TSS/链方向，现有分析仍缺少正式跨来源验证、L2 重采样稳定性、课程 motif/间距实验和最终生物学结论。
