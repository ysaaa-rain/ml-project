# DNA 大模型嵌入扩展方案

版本：M1.1
日期：2026-09-13

## 1. 这部分从哪里来

PR01-02 教师原文要求的主线是：从多物种启动子序列中发现 motif，分析位置、间距和组合，并做跨物种、跨数据集验证。原文没有要求 DNA 大模型。

课程项目池相邻题目 PR01-01 提到了 DNABERT-2、Nucleotide Transformer 等 DNA 预训练模型嵌入。本组借鉴这一建议，把“大模型嵌入”加入 PR01-02，作为小组新增的技术扩展。它不能替代 MEME、STREME、FIMO 和 Tomtom，也不能被表述成教师对本题的硬性要求。

## 2. 为什么值得加

MEME/FIMO 擅长回答“哪些短序列反复出现、出现在哪里”；DNA 大模型嵌入把整段序列压缩成向量，更适合观察“整段序列在整体上是否相似”。两条路线看到的信息不同：

- motif 路线可解释，能指出具体碱基模式和位置；
- 嵌入路线可能捕捉更分散、更长程的序列特征；
- 二者结合后，可以检查大模型看到的结构能否被具体 motif 解释，而不是只展示一张降维图。

因此，大模型在本项目中的角色是“补充表示和交叉验证”，不是新的主任务。

## 3. 新增研究问题

**RQ4：冻结 DNA 预训练模型得到的序列嵌入，能否提供 motif、位置和间距之外的稳定信息？这种补充信息能否跨数据源复现？**

RQ4 不改变 RQ1-RQ3。即使大模型因下载、许可证、显存或运行时间受限而无法完成，PR01-02 的 motif 主线仍应独立闭合。

## 4. 模型选择规则

第一轮只选择一个模型，不同时铺开多个大模型。候选为 DNABERT-2 和 Nucleotide Transformer，按以下顺序审计后再锁定：

1. 模型权重和代码是否能稳定获取；
2. 许可证是否允许课程项目使用和展示；
3. 最大输入长度是否覆盖统一启动子窗口；
4. CPU/GPU 内存和预计运行时间是否可接受；
5. tokenizer、模型 revision 和池化方式能否完整记录。

第一轮保持模型参数冻结，不做 LoRA 或全量微调。这样可以降低算力和过拟合风险，也便于判断预训练表示本身是否有用。

## 5. 输入和输出

### 输入

- 与 MEME 主线完全相同的清洗后启动子序列；
- 统一方向和 TSS 相对窗口；
- 在特征提取前完成 discovery/validation 和近同源序列簇隔离；
- 物种、数据源、σ 因子和证据等级只作为分组或评测元数据，不拼进 DNA 序列文本。

### 输出

- 每条序列一个固定长度的 sequence embedding；
- 可选的逐 token embedding，仅在需要定位局部信号且资源允许时保留；
- 模型 ID、revision、tokenizer、最大长度、截断规则、池化方式、设备、数据类型和批大小；
- 输入文件 SHA256、序列 ID 顺序和输出文件 SHA256。

模型权重和大体积 embedding 默认不提交 Git，只提交配置、摘要指标、小型图表和可重建记录。

## 7. 评测方法

主任务仍是无监督模式发现。评测分三层：

1. **无监督结构**：PCA/UMAP 只用于展示；聚类质量报告 silhouette 等内部指标。
2. **带标签诊断**：用 σ 因子、物种或数据源计算 kNN 一致性、ARI/NMI；这些标签只用于解释，不把项目改成分类任务。
3. **轻量探针**：可选线性分类器只作为“嵌入含有什么信息”的诊断，报告 macro-F1 和交叉验证结果，不称为项目主模型。

最关键的对照是：

| 表示 | 包含内容 | 要回答的问题 |
| --- | --- | --- |
| motif-only | motif 出现、位置、分数、间距 | 传统可解释特征能解释多少结构 |
| embedding-only | 冻结大模型向量 | 大模型是否捕捉到额外信息 |
| combined | motif 特征 + embedding | 二者结合是否稳定优于单独使用 |

只有在独立验证集或跨来源评测中仍有稳定增益，才可以说嵌入“提供了补充信息”。一张好看的 UMAP 图不能单独作为结论。

## 8. 泄漏和偏差控制

- 先按近同源序列簇划分，再提取和评测嵌入；
- discovery 上确定池化、降维和聚类设置，validation 上只复核；
- 检查嵌入是否主要编码序列长度、GC 含量、N 比例或数据源格式；
- 比较长度/GC 匹配子集，必要时对这些变量做残差化或分层分析；
- 不在验证集上微调模型或反复选择最佳参数；
- 对模型不可访问、输入过长、内存不足和运行超时保留失败日志。

## 9. 两周内的最小交付

两周阶段只承诺完成以下最小闭环：

1. 选定并记录一个可运行的冻结模型；
2. 在少量真实序列上完成 B5 smoke test；
3. 对完整可用样本提取 sequence embedding；
4. 生成一张降维图和一张 motif-only / embedding-only / combined 对照表；
5. 至少做一次按数据源或物种隔离的验证；
6. 如无法完成，记录具体阻塞，并保证 MEME/FIMO 主线继续推进。

本文件是实验设计，不是完成证明。截至 2026-09-13，仓库尚无模型权重、嵌入提取代码或真实嵌入实验结果。
