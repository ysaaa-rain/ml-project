# PR01-02 新两周实验推进计划

计划周期：2026-09-14 至 2026-09-27
制定依据：截至 2026-09-16 的仓库真实状态；日期表保留原计划节奏，实际执行以进度日志为准
总目标：用经过来源和质量审计的真实启动子数据，完成一轮可追溯的 DNA 大模型 embedding 实验，并形成有边界的阶段结论。

## 一、当前起点

计划制定时已经完成：

- 问题建模和 RQ1-RQ3；
- 数据清洗、TSS 窗口、近同源防泄漏、N0/N1 背景和 B0 校准代码；
- 固定版本的 Nucleotide Transformer 真实权重 smoke；
- L0 embedding、L1 聚类/近邻、L2 遮挡分析入口；
- 63 个自动化测试全部通过；当前仓库在真实数据适配后为 74 个测试全部通过。

计划制定时还没有完成、截至 09-16 已推进的数据项：

- RegulonDB/DBTBS 等真实数据的版本、许可、字段和 SHA256 审计；（已完成第一轮，许可边界仍待确认）
- 正式数据的 TSS 窗口和 discovery/validation 划分；（已完成来源原生窗口和初步 split，统一 TSS 窗口仍待 Gate A）
- 真实数据上的完整 embedding、跨来源验证和生物学结论；
- 老师要求的全序列/分组 MEME/DREME motif、FIMO 定位及间距/排列分析。

所以接下来不再继续扩展算法，而是优先把真实数据和实验闭环做扎实。

~~~text

    ↓

        ↓
~~~

## 四、四个阶段门槛

### Gate A：数据可以进入正式模型

必须同时满足：

- 来源、版本、访问日期、许可和 SHA256 已记录；
- TSS、链方向、窗口定义和 sigma 字段已核对；
- 近同源序列不会跨 discovery/validation；
- 清洗结果和删除原因可追溯。

### Gate B：可以运行正式 embedding

必须同时满足：

- 模型 ID 和 revision 固定；
- tokenizer、pooling、截断、设备、批大小和随机种子固定；
- discovery、validation、背景集已准备好；
- embedding 运行资源已经用 pilot 测过。

### Gate C：可以讨论 embedding 结构

必须同时满足：

- 向量、索引、配置和输入哈希齐全；
- 聚类和近邻不只展示单张图；
- 有重采样稳定性和偏差诊断；
- 至少有一个背景或负对照；
- 结果没有把 demo/pilot 当正式结论。

### Gate D：可以形成阶段结论

必须同时满足：

- 重要窗口在固定规则下得到，并在独立数据中复核；
- 至少完成一次跨来源或来源内严格重采样验证；
- 报告样本量、效应量、失败案例和局限性；
- 传统基线只解释结果，不替代大模型结果。

## 六、异常情况下怎么调整

- 数据来源许可不清：暂停下载，换用课程允许的数据或只完成代码验证，不绕过许可；
- 真实数据字段对不上：保留缺失并降级结论，不人为补齐 sigma/TSS；
- 模型资源不够：先减小 batch、分批提取或改 CPU；不随意更换模型和 revision；
- 某组样本太少：只做描述性分析，不做强显著性结论；
- 第二来源不可比：把 RQ3 降级为来源内重采样稳定性，并在报告中明确；
- MEME Suite 仍不可用：保留 B0 和大模型结果，记录环境限制，不把传统基线伪装成已完成；
- embedding 主要反映物种、来源、长度或 GC：停止生物学解释，先处理混杂；
- 结果不稳定：优先检查数据泄漏、窗口定义和随机性，不靠增加算法数量解决。

不按时间制造空提交，只在可验收节点提交并推送：

~~~text

validation: 完成跨来源复现
baseline: 增加最小传统解释对照
docs: 固化阶段结果与证据边界
~~~

每次提交前运行：

~~~bash
python -m pytest -q
python -m compileall -q preprocessing models experiments tests
git diff --check
~~~

本计划的最终交付不是“跑了多少算法”，而是同时回答老师的 motif/间距/跨数据集问题和大模型表示问题：大模型表示中看到了什么、这些结构是否稳定、能否跨来源复现、哪些只是数据偏差，以及课程 motif 线能否提供一致的交叉证据。
