## 阶段门槛

### Gate A：允许进入真实实验

- 数据来源、版本、访问日期、许可/使用条件和 SHA256 已记录；
- promoter 序列、TSS、链方向和 σ 标签字段含义已核对；
- 无法核实的字段保留缺失，不推断填充。

### Gate B：允许运行大模型主线

- 真实数据通过质量报告；
- 发现集、验证集和背景集已隔离；
- TSS 窗口和随机种子已锁定；
- 模型许可证、revision、tokenizer、最大长度、设备和预计资源已记录。

### Gate C：允许形成大模型阶段结论

- embedding、聚类、检索和局部解释可追溯到模型 revision、输入哈希和配置；
- 至少有一个负对照；
- 报告样本数、效应量、FDR 和局限性；
- demo、pilot 与正式实验结果分开保存和表述。

### Gate D：允许加入传统解释

- 大模型候选重要区域已经固定，不能根据 MEME 结果反向挑选窗口；
- B0 与一套 MEME/STREME/FIMO 足以构成传统小基线；
- 传统结果用于解释和核验，不以运行更多传统算法替代大模型主结果；
- UMAP/PCA 仍仅作展示，不把视觉分群直接写成结论。

## Git 提交节奏

每个节点原则上形成一个主题明确的提交，例如：

~~~text
data: 记录RegulonDB来源版本与原始文件哈希
feat: 增加RegulonDB字段适配器
exp: 记录真实数据M1质量审计结果
chore: 锁定DNA预训练模型版本与运行环境
exp: 完成冻结DNA模型嵌入smoke与追踪记录
analysis: 完成embedding聚类与近邻检索
analysis: 增加局部窗口遮挡解释
baseline: 增加最小PWM与MEME解释对照
~~~

提交以可验证进展为准，不为制造时间间隔而提交空文件、重复内容或未经运行的结果。

## 风险与调整规则

- 若数据下载或许可在 S1-S2 未解决，暂停正式实验，优先使用课程提供且允许使用的数据，不抓取受限内容；
- 若主模型超出本机资源，优先换用同系列较小型号、缩小 batch 或采用分批提取，并记录调整；
- 若某 σ 因子组样本量不足，该组降级为描述性结果，不进行强显著性结论；
- 若第二数据源字段无法与第一来源对齐，S12 改为来源内重采样稳定性，并明确不能回答完整 RQ3；
- 若候选模型无法下载或许可证不清，切换到另一个经审计的 DNA 预训练模型；不自动退回传统算法主线；
- 大模型第一轮先做冻结 embedding，LoRA 或对比学习只在主基线完成后启动；
- MEME/FIMO 只占最后的小型解释节点，强度关联和 motif 组合网络不挤占大模型主线。
