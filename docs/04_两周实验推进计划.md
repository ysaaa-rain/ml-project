## 阶段门槛

### Gate A：允许进入真实实验

- 数据来源、版本、访问日期、许可/使用条件和 SHA256 已记录；
- promoter 序列、TSS、链方向和 σ 标签字段含义已核对；
- 无法核实的字段保留缺失，不推断填充。

### Gate B：允许运行 motif 发现

- 真实数据通过质量报告；
- 发现集、验证集和背景集已隔离；
- TSS 窗口和随机种子已锁定；
- MEME Suite 预检通过并记录版本。

### Gate C：允许形成阶段结论

- MEME/STREME 输出可追溯到输入哈希和配置；
- FIMO/Tomtom 提供正式显著性；
- 至少有一个负对照；
- 报告样本数、效应量、FDR 和局限性；
- demo、pilot 与正式实验结果分开保存和表述。

### Gate D：允许声称大模型嵌入有效

- 模型 ID、revision、tokenizer、池化、输入长度、设备和输入哈希均已记录；
- 使用与 motif 主线相同的 discovery/validation 和同源簇隔离；
- 已比较 motif-only、embedding-only 和 combined；
- 增益在独立来源或物种上复现，且不是长度、GC 或来源偏差造成；
- UMAP/PCA 仅作展示，不把视觉分群直接写成结论。

## Git 提交节奏

每个节点原则上形成一个主题明确的提交，例如：

~~~text
data: 记录RegulonDB来源版本与原始文件哈希
feat: 增加RegulonDB字段适配器
exp: 记录真实数据M1质量审计结果
chore: 锁定MEME Suite版本与运行环境
exp: 完成全体序列MEME基线
analysis: 增加FIMO定位与已知元件对比
exp: 完成冻结DNA模型嵌入smoke与追踪记录
analysis: 比较motif与embedding表示的互补性
~~~

提交以可验证进展为准，不为制造时间间隔而提交空文件、重复内容或未经运行的结果。

## 风险与调整规则

- 若数据下载或许可在 S1-S2 未解决，暂停正式实验，优先使用课程提供且允许使用的数据，不抓取受限内容；
- 若 Windows 无法稳定运行 MEME Suite，S6 改为 WSL 或容器环境，并记录镜像/版本；
- 若某 σ 因子组样本量不足，该组降级为描述性结果，不进行强显著性结论；
- 若第二数据源字段无法与第一来源对齐，S12 改为来源内重采样稳定性，并明确不能回答完整 RQ3；
- 若模型无法下载、许可证不清、资源不足或完整提取超时，只保留 B5 小样本 smoke 与失败记录，不影响 MEME/FIMO 主线；
- 大模型第一轮只做冻结 embedding，不在两周内承诺 LoRA 或全量微调；
- 扩展项“强度关联”和“motif 组合网络”不挤占 motif 主线和嵌入最小对照，前两者闭合后再择优启动。
