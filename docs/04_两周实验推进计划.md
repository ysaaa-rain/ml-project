# PR01-02 后续实验推进计划

更新日期：2026-10-03
本计划替代已过期的历史日期安排；它按依赖和验收条件排序，不把未运行的分析写成已完成。

## 总目标

完成可复核的一条主线：TJU Pan 六物种正类启动子 → MEME/STREME 发现 → 与参考元件比较 → FIMO 定位 → 位置/频率/间距/排列 → 跨物种及独立数据集复核。RegulonDB 专门补足 σ 分组与跨数据集比较；DBTBS 只作可选增强。

## 当前入口与进度

- 数据：59 个云盘载荷的 SHA256 校验已通过；六物种正类与负类对照的 FASTA 输入已核验并生成。
- M3 输入规模：正类合计 9,724 条；四条 80 bp 负类对照排除，其余有效负类共 8,642 条。
- 质量记录：正类序列均为 81 bp 且只含 A/C/G/T。Bradyrhizobium、E. coli、Staphylococcus 的正类存在完全相同序列重复；Bradyrhizobium 与 E. coli 的拆分间存在少量精确重复，后续独立验证必须再次去重。
- 运行：六物种全量 MEME 与首轮 FIMO 均已完成；当前状态以 results/motif/tjupan_m3_20261003/ 下各阶段 manifest 为准。
- 方向：云盘表没有链方向列。除非完成独立方向审计，结果先报告序列内位置，不冒称 TSS 有符号位置。

## 阶段门槛

### A. M1 / M2 收口

1. 把云盘目录、每个物种记录数、正负标签、长度异常、重复与拆分交叠写入机器可读和中文记录。
2. 六物种样本数、GC、长度、碱基组成及拆分重复的描述性 EDA 已完成；与 RegulonDB 辅助分析分开报告。TSS-relative 解读仍受方向证据限制。
3. 记录序列方向、TSS、σ 标签与数据许可目前缺什么证据；不从序列内容猜字段。

验收：报告表格可由输入和脚本复核；原始数据不进普通 Git。

### B. M3 motif 发现与中期汇报

1. 先检查第一组 MEME 是否有正常文本/XML、退出码、输入和背景样本数；再依次检查其余五个物种。
2. 对每个物种检查 motif 数量/宽度、E-value、位点分布、低复杂度、正负对照差异和运行日志；搜索退出码为零本身不等于结果通过生物学质检。
3. 用适用范围清楚的参考矩阵做 Tomtom 初比；理想化 −10/−35/UP 共识只作为参考，不把小参考库 p/q 值包装成确认性检验。
4. 整理 6 物种一致的 summary、logo/图、manifest 与解释边界，完成 M3 中期汇报材料。

验收：六物种全部有独立成功记录；输入/输出 SHA256、MEME 版本、参数和失败/排除理由齐全。完成以上门槛才标记 M3 完成。

### C. M4 定位与模式验证

首轮 FIMO 已完成并形成 `reports/M4_TJUPan_FIMO阶段报告.md`。它扫描 60 个物种专属 motif 矩阵，按每个 motif 的 FIMO q≤0.05 输出 353 个位点，并按独特序列统计覆盖；坐标仍为输入 FASTA 内 1–81 bp。正负类差异的 Fisher 检验已对 60 个“物种×motif”项作 BH 校正。该结果是同数据集发现后扫描的探索性结果。

1. 制作 M3 中期汇报材料，汇报六物种 MEME 与已知矩阵初比，并把首轮 FIMO 标为后续探索，不混淆 M3 验收边界。
2. 核查 motif 命中与理想化 −10/−35/UP 序列位点的真实重叠；先审计 81 bp 字符串的转录方向，再决定是否报告 TSS 坐标。
3. 统计 motif pair 共现、次序、重叠、带符号间距和绝对间距；与组成匹配背景或适当置换基线比较。
4. 跨物种比较采用一致的 motif 相似度、覆盖率和效应指标。跨数据集比较前，在两来源间去除完全相同、反向互补和高相似序列，并披露过滤前后样本量。
5. DBTBS 不作为阻塞条件；若使用，先确认数据记录、坐标/方向与许可。缺乏坐标时只允许序列层比较。
