# PR01-02 课程实践候选与展示规范

日期：2026-10-27。用户希望项目以 motif 发现和可解释展示为重点，便于课程实践讨论。本规范用于新建探索视图及后续实验的结果组织，历史实验的参数、数据和已经记录的结论继续可追溯。

## 候选与图表

1. 传统方法和Embedding运行均可展示全部实际产生的候选；表中标注方法、数据来源、分组、背景、宽度、共识及可用的序列logo/碱基概率。跨运行重复记录不合并成新的独立motif。
2. 同时保留天然对照和Shuffle各自的命中、p/q或其他已有指标；不同工具、对照和校正家族的数字不直接混用。无数据记缺失，不补造0或结果。
3. 真实序列候选可描述与参考模式的相似、重叠长度、偏移、方向和位置分布；相似或高激活不自动代表生物功能或独立验证。
4. 合成任务可从已冻结候选中用已知植入参考做局部重叠、双向和位置容差评价，同时展示相似度、重叠长度与空白命中。当前总览使用至少8/12bp、±3bp投影容差，未额外设置相似度入选截止值；这是事后参考辅助探索，不是全自动发现能力或新的盲验证。
5. 对照模型和不同数据种子的结果保留；同一数据上多个算法种子先平均，再按数据种子汇总。图表须提供分母、单位与数据来源。

## 实验与报告

- 真实数据以冻结v2的Discovery为发现/训练来源；天然负类和已有dinucleotide shuffle分别解释。当前用户视角鼓励报告可观察的候选，但不改写历史显著性、原始PWM、数据或验证状态。
- 开展新实验时，先记录输入、方法、候选排序和实际输出；对于已观察过的Development/Test或既有Holdout，明确属于探索，不能包装成全新盲确认。产生新假设或更改算法后，应另存运行并使用相应未用于调参的数据评价。
- 面向课程汇报可优先展示有代表性的logo、局部相似、位置/间距和对照图，并说明实例、PWM和数据来源。选取例子时记录可复现的选择规则，不从已经看过的验证结果中挑选后声称预先确认。
- RQ1的候选、RQ2的σ组差异和RQ3的跨物种/跨来源复现分别呈现；DBTBS与TJU存在重叠，不作为独立外部统计验证。
