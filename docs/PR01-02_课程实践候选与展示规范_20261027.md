# PR01-02 课程实践候选与评价规范

2026-10-27 更新：以 MEME/STREME 已使用的真实基础数据和冻结划分为共同输入；各条线路的横向比较统一采用适合课程实践的较宽松候选展示与评价规则。CNN 尚待收尾，未来加入时遵循相同数据与评价口径。

- 所有方法均可展示实际产生的候选，不以全长匹配或单一显著性门槛作为唯一展示条件。记录方法、来源、分组、背景、宽度及图示；跨运行重复候选不算独立发现。
- 统一评价可考虑局部重叠、正反向及位置偏移；适用于不同宽度的具体阈值、候选预算、排序和背景规则应在新一轮运行前写入协议，并对参与比较的所有方法一致应用。展示匹配长度和相似度，避免不相关短片段被误读。
- 对同一物种和划分，统一扫描全部参与方法的 PWM，分别呈现天然负类与配对 Shuffle 对照；两者不能混用。未取得的数据记缺失，实测结果如实保留。
- 先检查传统方法 PWM 和 Embedding 候选的来源与数据哈希；缺失传统 PWM 要恢复或按原数据参数补跑，不用其他数据的结果替代。
- 可优先展示真实、可追溯、有代表性的候选与 Logo，同时保留完整明细。参考相似不等于功能确认；历史实验、原始数据和冻结统计不改写。
- 真实数据以 Discovery 为候选产生和规则设定来源；Development 用于统一观察，已观察过的结果按探索解释。CNN 有监督条件时注明；DBTBS 与 TJU 存在重叠，不作为独立外部统计验证。

执行顺序见[真实数据统一比较重做计划](PR01-02_真实数据统一比较重做计划_20261027.md)。
