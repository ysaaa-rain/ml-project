## 需从**本地未公开原生文件**新增汇总的关键问题

1. **真实已知注释位点与预测位点的重叠**：仅在能建立`原始来源 promoter ID + 可靠 TSS/方向/基因组坐标 + 实验性 −10/−35 元件坐标`映射的 RegulonDB/DBTBS 序列上做。给出每来源/σ组/方法、每个 motif、元素类型的可映射总序列数 N、已注释真实元件总位点数、预测命中数、预测与注释 `≥1bp` 相交数及分母对应的重合率、exact-boundary/≥50% reciprocal-overlap 可选敏感性与 strand、一对多去重规则。不能仅凭同一 81bp DNA 序列相同就假设 TSS genomic coordinate 可唯一转移。**TJU 六物种本身没有逐条可靠基因组坐标**：无法精确映射的只报 TSS 相对窗口命中，不得报告“真实注释位点重合率”。
2. **TSS 相对位置/−10、−35 窗口**：对 MEME/STREME 的原生显著 motif 和原 17 候选，在 discovery / development 分开汇总正向与反向扫描位点、motif 中心相对 TSS `(start+stop)/2−61`、主要命中位置、窗口内命中率，指定分母；允许对 raw p<1e−4 及原生 FIMO q≤0.05 分开列，但不得混写或根据 holdout 改阈值。解释 Genomic strand 与相对输入 strand 的区别。
3. **解释 B. subtilis 2 条探索性 holdout 阳性**：给出现有明确检验的自然对照组成、predicted sites 相对 TSS 分布、与实验注释 −10/−35 的位置关系、是否 T-rich/AT-rich/−35上游或TSS下游，是否源数据重复/高同源导致统计偏差。不得借此事后改动原先确认性结论。
4. **UP element / TFBS**：汇总本地/公开参考库是否有与当前物种匹配、具有实验支持且可以审计坐标的 UP/TFBS 真实注释：按物种、类型、样本数、PMID/证据层级列明。没有可靠数据则写`尚无可验证覆盖`；不拿四个理想共识凑正式恢复率；不得再分发受限内容。
5. **检查证据与漏数**：首次 FIMO 的 12 次 SEA、raw p<1e−4 的 1494 位点、严格 q 的低检出能否以同一分母解释；一项 Staphylococcus development 原严格位点 19 vs 全表 14 的 q 估计差异要明确独立显示，不混作两个版本的验证。核对现在 540 PWM 中任意 Tomtom/SEA/FIMO 的候选筛选是否混入非原生显著 PWM，所有结论按 `all_reported` 与 `native_significant_only` 双口径分列。
