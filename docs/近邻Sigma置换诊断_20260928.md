# RegulonDB TSS 子集的 sigma 近邻置换诊断

日期：2026-09-28。分析对象是 2026-09-24 固定模型运行产生的 3,807 条 RegulonDB E. coli discovery 序列和固定 5-NN 图；本轮没有重新提取向量或调整近邻参数。

## 规则与复现

仅统计近邻关系两端均有已知 sigma 标签的有向边。保留原有 kNN 图、重复的反向边和未知标签所在节点；随机置换每条序列的已知 sigma 标签，共 2,000 次，固定种子 `20260928`。全局置换保持各 sigma 组样本量；GC 分层置换先按已知标签序列的 GC fraction 分成最多 10 个分位组，再在每组内置换。单侧富集 p 值按 `(1 + 随机同组率 >= 观察同组率的次数) / 2001` 计算。置换区间为随机同组率的 2.5% 和 97.5% 分位数，不是观察同组率的置信区间。

```bash
python -B -m experiments.sigma_neighbor_permutation \
  --embedding-dir results/l0_embedding_regulondb_tss_20260924 \
  --output results/l1_structure_regulondb_tss_20260924/sigma_neighbor_permutation.json \
  --permutations 2000 --seed 20260928
```

输入文件 SHA256：`embedding_clusters.tsv` 为 `60d5c1f240bef9894443d6c978e28b8608bf49164e96d102be29049c0ba85758`；`nearest_neighbors.tsv` 为 `4e28aad217dc076e2734f6403a8511734b1981d1e009aa061c7c25be6c12181c`。结果 JSON 留在本地被 Git 忽略的 `results/` 目录。

| 指标 | 结果 |
| --- | ---: |
| 已知 sigma 序列数 | 3,167 |
| 两端标签已知的有向近邻边 | 13,257 |
| 观察同组率 | 41.691% |
| 全局置换均值；95% 随机区间 | 41.689%；40.612%–42.838% |
| 全局置换单侧富集 p 值 | 0.488 |
| GC 分层置换均值；95% 随机区间 | 42.045%；40.937%–43.185% |
| GC 分层置换单侧富集 p 值 | 0.735 |

观察值与全局随机均值只差约 0.003 个百分点；GC 分层后比随机均值低约 0.354 个百分点。两种固定图置换对照均未显示 sigma 同组近邻富集。这加强了 9 月 24 日描述性诊断的负面判断，但仅是单一来源、单一物种、discovery 集的标签检验。置换不检验重新提取 embedding 或重新建立 kNN 图时的稳定性，也不回答 motif、跨来源复现或生物学机制问题。
