## 五、交给丙时请特别转达四句话

1. **不要**引用 `乙_位置附录_20261007.md` 里 DBTBS/TJU 的位置数字——
   问答记录与仓库现行规范在这件事上互相矛盾，等队长裁决。
2. **不要**把"精确共识串命中率低"写成"该位置没有偏好"。
   -10 窗口实测碱基 `TAAAAT` 与共识 `TATAAT` 有 5/6 位一致，
   只是**精确共识串本身在真实启动子里很少出现**。
3. **不要**把跨来源的数字并排比较（RegulonDB 是大肠杆菌、DBTBS 是枯草芽孢杆菌，
   物种与 σ 命名体系都不同），也不要把 SigM / SigI / SigL 这类 n≤3 的组写成结论。
4. **引用 -35 box 位置时用中位数、并同时给离散程度**：
   Sigma70 的 -35 位置均值 −24.76 与中位数 −35.0 相差 10 bp，分布右偏，只用均值会误导。
   另：间距分布是**≤1 错配的敏感性口径**（精确口径下全库只有 1 对配对），引用时必须说明。
