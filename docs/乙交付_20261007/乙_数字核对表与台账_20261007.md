**重跑注意**：
- `00` 会重新下载 29.5 MB 的 zip（已存在则跳过）；

  **同一环境下重跑结果应完全一致**（`numpy.random.default_rng(20261005)`）；
- 其余脚本为确定性计算。

### 这个核对能证明什么、不能证明什么

| 能证明 | 不能证明 |
| --- | --- |
| 报告里写的数字与计算产物一致（无手抄错误） | 计算产物的口径选择是否正确 |
| 产出的表确实包含报告引用的数字 | 统计方法是否恰当 |
| 报告之间的数字不互相矛盾 | 数据本身是否可靠（那是甲的验收职责） |

**后三项由脚本内的口径注释、`02_headcount.py` 的三方交叉核对，
以及甲在 [甲_验收记录_20261006.md](甲_验收记录_20261006.md) 的验收共同覆盖。**

## 四、已知偏差与口径说明（照实登记）

| # | 事项 | 说明 | 影响 |
| --- | --- | --- | --- |
| 1 | RegulonDB `core` ∪ `extended` 唯一序列 3,812 而非 3,813 | 一对序列在两个 tier 各出现一次（同哈希不同 ID） | 只影响"唯一序列数"这一口径，不影响其他分析 |
| 2 | 1,169 条序列跨来源重复 | RegulonDB↔TJU 大肠杆菌 760、DBTBS↔TJU 枯草 409 | **这批不能计作独立验证样本** |
| 3 | TJU 无 σ 标签、无基因组坐标 | 18,349 条 | σ 分组与基因组坐标分析都不覆盖 TJU |
| 4 | σ 分组合计只覆盖 1,498 条（6.63%） | 单标签 + core 层口径 | 是"按向导分组比较"的样本上限 |
| 5 | 旧数据 14.5% 无法复现 | 定义未在仓库登记，窗口口径也不同（101bp/TSS 81 vs 81bp/TSS 61） | **报告里不得做新旧对比** |
| 6 | DBTBS/TJU 位置分析 | 与问答记录冲突，按裁决只作为附录 | **不得用于结论** |
| 7 | 覆盖率与唯一性 | 本分析按"记录数"计数；未按唯一序列去重 | 与甲的口径一致；若将来改为唯一序列口径，所有 n 需重算 |
| 8 | 多重比较校正的范围 | GC 比较与命中率比较**各自独立做 BH 校正** | 若跨族合并校正，q 值会变大（更保守） |
