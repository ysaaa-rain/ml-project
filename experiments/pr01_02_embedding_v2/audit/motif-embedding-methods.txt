下面按照你综述中的六类技术路线展开。为了便于后续把它整理成论文/课程材料，我把每一类都统一拆成四个问题：
1. 基本原理：motif是在哪里被“表示”出来的？
2. 核心算法：如何从模型内部表示中把 motif 提取出来？
3. Motif 评价：发现出来以后如何判断它是否可靠、有生物学意义？
4. 优缺点：这种路线真正解决了什么问题，又有什么局限？
需要特别区分一点：embedding本身并不等于 motif discovery。真正的技术链条通常是
序列 → 表示学习 → 特征/重要性提取 → motif 实例聚合 → motif 模型构建 → 生物学评价
你综述中的六类方法，主要区别就在于“从表示中如何提取 motif”这一环节。综述将其划分为 CNN 卷积核、预训练
LM embedding、SAE、注意力解释、GNN embedding、特征归因/ISM 六类。

二、CNN 卷积核作为 Motif Detector
代表方法包括 DeepBind、DeepSEA、scBasset。综述中将其定位为最早的一类深度学习 motif discovery 方法，并强
调第一层卷积核可以直接充当 motif scanner。
2.1 基本原理
假设 DNA 序列经过 one-hot encoding：
𝑋 ∈ {0, 1}4×𝐿
一个长度为 (k) 的卷积核：
𝑊 ∈ ℝ 4×𝑘
1
在序列上滑动：
𝑎𝑖 = 𝑓(𝑊 ⊙ 𝑋𝑖∶𝑖+𝑘−1 + 𝑏)
因此，一个卷积核实际上是在回答：
“这个位置附近是否出现了我学习到的这种序列模式？ ”
如果某个卷积核在大量具有相同功能的序列上都产生高响应，那么这个卷积核就很可能对应一个 motif。
因此 CNN 的特殊之处在于：
CNN filter ≈ motif detector

2.3 Motif 评价
这一类方法的评价通常分为三层。
￿ 与已知 motif 比较
使用：
• JASPAR
• HOCOMOCO
• CIS-BP
• TRANSFAC
等数据库。
常见方法是 TOMTOM。
核心思想是：
𝑀discovered ↔ 𝑀known
比较两个 PWM 的相似性。
￿ 分类/预测性能
如果这个 motif 被去掉之后模型性能下降：
Δ𝑃 𝑒𝑟𝑓𝑜𝑟𝑚𝑎𝑛𝑐𝑒 = 𝑃 𝑒𝑟𝑓𝑜𝑟𝑚𝑎𝑛𝑐𝑒(𝑀 ) − 𝑃 𝑒𝑟𝑓𝑜𝑟𝑚𝑎𝑛𝑐𝑒(𝑀 −motif)
则说明该 motif 对模型预测具有功能贡献。
￿ 生物学验证
例如：
• ChIP-seq binding
• A TAC-seq accessibility
• TF binding
• reporter assay
• mutagenesis
3
2.4 优点
最大优势是可解释性。
因为 motif 并不是从模型外部“猜”出来的，而是：
卷积核本身就是模型学习到的 pattern detector。
优点包括：
• 结构简单；
• motif 定位清晰；
• 易于转换成 PWM；
• 计算成本低；
• 结果容易解释。
2.5 缺点
￿ 一个 filter ≠ 一个纯粹 motif
现代 CNN 中，一个卷积核可能学习：
• motif；
• motif + context ；
• motif combination；
• 非生物学的统计模式。
因此“一个 kernel 就是一个 motif”其实只是近似。
￿ 局部感受野
CNN 天然偏向局部模式：
local pattern
对于：
𝑚𝑜𝑡𝑖𝑓𝐴 ⋯ 𝑚𝑜𝑡𝑖𝑓 𝐵
这种长距离组合关系不够自然。
￿ 监督依赖
模型通常是：
𝑠𝑒𝑞𝑢𝑒𝑛𝑐𝑒 → 𝑙𝑎𝑏𝑒𝑙
因此发现出来的是与预测任务相关的 motif，而不是所有潜在 motif。
三、预训练 DNA Language Model Embedding
代表包括 DNABERT、Nucleotide Transformer、GPN、HyenaDNA。综述将这一类定义为利用大规模未标注基因组
进行 MLM/CLM 预训练，再从 embedding 中提取 motif。
这里需要特别注意：
“预训练 LM”本身不是一种具体的 motif discovery algorithm 。
4
它提供的是一个更强的表示空间：
𝑓𝜃 ∶ 𝑠𝑒𝑞𝑢𝑒𝑛𝑐𝑒 → 𝑒𝑚𝑏𝑒𝑑𝑑𝑖𝑛𝑔
motif discovery 还需要后面的 extraction mechanism。
3.1 基本原理
以 MLM 为例：
𝑥1, 𝑥2, … , 𝑥𝐿
随机 mask 一些 token：
𝑥𝑖 → [𝑀 𝐴𝑆𝐾]
模型学习：
𝑃 (𝑥𝑖|𝑥∖𝑖)
经过大规模预训练后，embedding：
ℎ𝑖 = 𝑓𝜃(𝑥1, … , 𝑥𝐿)
包含上下文信息。
于是一个核心假设是：
如果某种序列模式具有稳定的生物学意义，那么预训练模型可能会在 embedding 中编码这种模式。
四、预训练 LM 的 motif discovery 怎么做？
这是这一类最容易混淆的地方。
实际上存在多种 extraction strategy：
路线 A：Attention
𝐸𝑚𝑏𝑒𝑑𝑑𝑖𝑛𝑔 → 𝐴𝑡𝑡𝑒𝑛𝑡𝑖𝑜𝑛 → ℎ𝑖𝑔ℎ − 𝑎𝑡𝑡𝑒𝑛𝑡𝑖𝑜𝑛𝑟𝑒𝑔𝑖𝑜𝑛 → 𝑚𝑜𝑡𝑖𝑓
对应 DNABERT-viz。
路线 B：输入重建
例如 GPN：
𝑒𝑚𝑏𝑒𝑑𝑑𝑖𝑛𝑔 → 𝑛𝑢𝑐𝑙𝑒𝑜𝑡𝑖𝑑𝑒𝑟𝑒𝑐𝑜𝑛𝑠𝑡𝑟𝑢𝑐𝑡𝑖𝑜𝑛
通过改变输入碱基观察重建概率变化。
路线 C：embedding clustering
ℎ𝑖 → 𝑐𝑙𝑢𝑠𝑡𝑒𝑟𝑖𝑛𝑔 → 𝑠𝑒𝑞𝑢𝑒𝑛𝑐𝑒𝑝𝑎𝑡𝑡𝑒𝑟𝑛
5
路线 D：后续解释模型
例如：
𝐿𝑀 𝑒𝑚𝑏𝑒𝑑𝑑𝑖𝑛𝑔 → 𝑆𝐴𝐸 → 𝑠𝑝𝑎𝑟𝑠𝑒𝑓𝑒𝑎𝑡𝑢𝑟𝑒 → 𝑚𝑜𝑡𝑖𝑓
这实际上已经进入下一类 SAE。
因此更严谨地说：
Pretrained LM 是 motif discovery 的 representation backbone，而不是单独的 motif extraction
algorithm。

主要包括：

￿ motif enrichment

￿ predictive importance
通过：

• mutation

判断 motif 是否影响模型预测。
￿ biological downstream task
例如：
• TF binding
• chromatin accessibility
• enhancer activity
• splice prediction
• variant effect prediction

优点
相对于 CNN：
￿ 不需要大量 motif 标注
可以直接利用：
genome-scale unlabeled sequence
￿ 上下文感知
embedding 不只是局部 (k)-mer：
ℎ𝑖 = 𝑓(𝑥1, … , 𝑥𝐿)
因此可能包含：
𝑙𝑜𝑐𝑎𝑙 𝑚𝑜𝑡𝑖𝑓 + 𝑐𝑜𝑛𝑡𝑒𝑥𝑡 + 𝑙𝑜𝑛𝑔 − 𝑟𝑎𝑛𝑔𝑒 𝑑𝑒𝑝𝑒𝑛𝑑𝑒𝑛𝑐𝑦
￿ 跨任务迁移
同一个 pretrained model 可以用于：

最主要的问题是：

也就是说：

这三类方法本质上都是在解决：

六、SAE：从 Embedding 中分解 Motif
这是你综述中最值得重点展开的一类。综述将 MotifAE、InterPLM、SAE-RNA 归入这一范式，并强调其核心是把
LM embedding 转换成高维、稀疏的 latent features。
7
6.1 基本原理
假设 PLM 输出：
𝑥 ∈ ℝ 𝑑
普通 embedding 的问题是：
一个 embedding dimension 往往混合编码多个生物学概念。
即：
𝑥 = 𝑓𝑒𝑎𝑡𝑢𝑟𝑒1 + 𝑓𝑒𝑎𝑡𝑢𝑟𝑒2 + 𝑓𝑒𝑎𝑡𝑢𝑟𝑒3 + ⋯
这就是所谓的 polysemanticity / feature superposition 问题。
SAE 希望找到：
𝑧 ∈ ℝ 𝐷, 𝐷 ≫ 𝑑
且 (z) 是稀疏的：
‖𝑧‖0 ≪ 𝐷
然后：
𝑥 ≈ 𝐷𝑧
其中：
• (x)：PLM embedding
• (z)：sparse latent feature
• (D)：decoder dictionary

优势
￿ 无监督

￿ 稀疏度存在 trade-off
太稀疏：
reconstruction 差。
太不稀疏：
interpretability 差。
￿ 训练成本高
尤其是：

规模的 SAE。

十五、Attention 方法的关键问题
这是这一类方法必须强调的理论问题：
𝐴𝑡𝑡𝑒𝑛𝑡𝑖𝑜𝑛 ≠ 𝐸𝑥𝑝𝑙𝑎𝑛𝑎𝑡𝑖𝑜𝑛
即：
attention weight 高，并不必然意味着该位置对最终 prediction 的因果贡献高。

因此：

• 也可能关注语法关系；
• 也可能只是模型内部的信息路由机制。
综述也明确指出 attention 权重与功能重要性并不完全等价。

二十、特征归因与 In Silico Mutagenesis
这一类包括：

你原综述目前对“motif 评价”的讨论相对弱。第 5.1 节只指出目前评价过度依赖 JASPAR、ELM、CIS-BP 等已知数

Level 1：Pattern-level

• PWM similarity
• sequence logo
• TOMTOM
• edit distance
• information content

Level 2：Enrichment-level
评价 motif 是否在目标数据中显著富集。

𝑂𝑅 = 𝑎/𝑏
𝑐/𝑑

或者：
𝐹 (𝑋 + 𝑀 ) − 𝐹 (𝑋)

三十一、我认为这篇综述最值得修改的一点
目前你的六分类存在一定的分类层级混杂。
例如：
CNN、GNN 是模型架构；DNABERT、NT、GPN 是表示学习模型；SAE 是解释模型；Attention 是解
