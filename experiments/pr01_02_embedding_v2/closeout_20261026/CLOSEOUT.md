# 当前 ProkBERT 聚类线路收束记录

状态：2026-10-26 起阶段性收束。收束对象为冻结 ProkBERT-mini 局部表示、PCA/K-Means、实例筛选/对齐与 PWM 重建这套流程；BERT 不再作为当前调参对象。历史结果保留作对照，不推广为所有 DNA 语言模型无效。

## 已完成证据

| 批次 | 实际工作 | 可支持的结论 |
| --- | --- | --- |
| [定位与 mini-c](../bottleneck_20261025/REPORT.md) | 42次拟合，局部重编码和有序拼接 | 两种子15%退化F1约0.900，One-hot约0.919；30%退化失败 |
| [复核与瓶颈](../validation_20261025/REPORT.md) | 324次聚类、414组PWM、25个监督探针 | 原流程15%退化约0.695，PCA128约0.790，One-hot约0.900；可读信息不等于无监督发现成功 |
| [对齐与背景拒绝](../refinement_20261026/REPORT.md) | 48次聚类、240组输出 | 30%退化背景拒绝改善自身至约0.482，但相对One-hot仅1/3数据种子胜出、误报更高 |
| [独立预算复核](../budget_validation_20261026/REPORT.md) | 135次聚类、270组PWM池、900组评价 | 双方各5候选，BERT F1约0.295、One-hot48约0.543；5/5新数据种子均落后，误报约0.163/0.146 |

四轮合计549次实际聚类拟合；候选子集和监督探针不冒充新聚类。各轮数据不同，不能把均值拼成连续的提升/下降曲线。末轮预设进一步研究门槛未通过；5组数据双侧符号翻转p=0.0625，不声称总体显著劣势。

保留代码、协议、测试、汇总、排名/预算锁、图表、哈希、负面结果及本地人工序列、实例、PWM、拟合对象。真实Holdout未使用；没有新增生物学功能motif结论。全序列旧缓存腾退范围与实际文件记录见 `cleanup_plan.json`、`cleanup_result.json`。

## 缓存清理与复现

仅腾退 `../cache/<六物种>/*.npy` 中与已存manifest哈希一致、Git忽略且未被末轮历史保护清单引用的可再生成编码数组；保留原始数据、权重、源码、cache_manifest.json和index.tsv。各轮独立实验的artifacts、失败记录和日志均保留。未知的PPT草稿、用户已有删除和其他目录不纳入清理。

这些旧缓存不再是“当前可直接读取的特征文件”。如需重做早期全物种表示，先在独立新目录使用保留的固定模型/代码/config以及对应index.tsv中的冻结输入调用 `encoder.cache_features`，再逐文件与历史cache_manifest.json比较哈希；不同数值环境未必逐字节一致，应报告差异。现存PWM/实例/模型核验不依赖这些编码数组。清理后的可用性以cleanup_result.json为准，旧manifest保留为生成时快照。
